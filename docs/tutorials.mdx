title: 简介
---

在本教程中，我们将构建一个小型（Web）应用程序，作为乐谱的通用查看器和播放器。我们正在构建的结果的一个类似版本可以在 [alphaTab 主页](/) 上看到。

我们将添加一个基本的查看器，从给定来源加载文件。然后我们将逐步为这个简单的显示添加更多高级功能，例如：

- 音轨选择器
- 用户控制显示更改
- 播放器

本教程不需要任何关于如何使用 alphaTab 的预备知识，但需要具备所开发平台的相关知识。alphaTab 是一个 SDK 而非即插即用的解决方案，最终如何规划和设计应用程序的外观和行为将完全取决于您。

这些教程旨在学习配置和与 alphaTab 交互所需的所有步骤。
