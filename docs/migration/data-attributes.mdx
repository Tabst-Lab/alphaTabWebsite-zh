--- 
title: 数据属性
---

> [!WARNING]
> 通过数据属性配置 alphaTab 已在 1.5 版本中弃用，并将在 2.x 版本中移除。

HTML 数据属性是一种相当常见的机制，用于将配置从 DOM 传递到 JavaScript 框架。这种做法在 Angular 或 React 等前端框架之外相当常见，并且被 Bootstrap 和 jQuery 等框架所熟知。

为了减少我们需要维护和支持的配置机制数量，数据属性配置将在 2.x 版本中作为破坏性变更移除。alphaTab 无论如何都需要通过 JavaScript 进行最低程度的初始化（例如 `new AlphaTabApi(element, settings)`），因此迁移到设置对象相当简单。开发者仍然可以根据自定义属性需求来填充设置对象。

在移除之前，我们将保持向后兼容性，但同时已从 API 参考文档中删除了所有相关文档。

## 迁移

要进行迁移，请将 HTML DOM 中相应数据属性的所有属性移动到 JavaScript 设置对象中。

### 变更前

数据属性以 `data-category-setting` 的形式添加到 DOM 元素上。

```html
<div id="alphaTab" 
        data-core-file="test.gp"
        data-display-layoutmode="horizontal" 
        data-player-enableplayer="true"></div>
<script type="module">
import * as alphaTab from '@coderline/alphaTab';
const element = document.querySelector('#alphaTab');
const api = new alphaTab.AlphaTabApi(element);
</script>
```

### 变更后（JSON 对象）

设置根据参考文档定义在一个纯 JSON 对象中（我们有类型定义）。
JSON 对象将在内部转换为真正的设置对象。后续的修改需要在 `api.settings` 上进行。

```html
<div id="alphaTab"></div>
<script type="module">
import * as alphaTab from '@coderline/alphaTab';
const element = document.querySelector('#alphaTab');
/** @type {alphaTab.json.SettingsJson} */
const settings = {
    core: {
        file: element.dataset.file // 您仍然可以自行加载数据属性
    },
    display: {
        layoutMode: "horizontal" // 或者更好：alphaTab.LayoutMode.Horizontal
    },
    player: {
        enablePlayer: true
    }
};
const api = new alphaTab.AlphaTabApi(element, settings);
</script>
```

### 变更后（Settings 对象）

创建一个新的 `Settings` 实例，并在定义的属性上填充相应的值。
如果您需要基于默认值做出决策，或者想在多个 alphaTab 实例之间共享同一个对象，这将非常有用。

```html
<div id="alphaTab"></div>
<script type="module">
import * as alphaTab from '@coderline/alphaTab';
const element = document.querySelector('#alphaTab');
const settings = new alphaTab.Settings();
settings.core.file = "test.gp";
settings.display.layoutMode = alphaTab.LayoutMode.Horizontal;
settings.player.enablePlayer = true;
const api = new alphaTab.AlphaTabApi(element, settings);
</script>
```
