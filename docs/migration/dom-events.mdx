--- 
title: DOM 事件
---

> [!WARNING]
> 通过 DOM 事件监听 alphaTab 已在 1.5 版本中弃用，并将在 2.x 版本中移除。

DOM 事件是一种相当常见的机制，用于从 JavaScript 框架发出特殊事件。这种做法在 Angular 或 React 等前端框架之外相当常见，并且被 Bootstrap 和 jQuery 等框架所熟知。

为了减少我们需要维护和支持的事件机制数量，并提高性能，DOM 事件将在 2.x 版本中作为破坏性变更移除。alphaTab 无论如何都需要通过 JavaScript 进行最低程度的初始化（例如 `new AlphaTabApi(element, settings)`），因此迁移到 JavaScript 事件相当简单。

在移除之前，我们将保持向后兼容性，但同时已从 API 参考文档中删除了所有相关文档。

## 迁移

要进行迁移，请将 HTML DOM 中相应数据属性的所有属性移动到 JavaScript 设置对象中。

### 变更前

事件监听器通过 `alphaTab.eventName` 注册到 DOM 元素上。事件数据包含在 `e.detail` 中。

```html
<div id="alphaTab"></div>
<script type="module">
import * as alphaTab from '@coderline/alphaTab';
const element = document.querySelector('#alphaTab');
element.addEventListener('alphaTab.error', e => {
    sendErrorToAnalytics(e.detail);
}, false);
element.addEventListener('alphaTab.playerPositionChanged', e => {
    updatePlayerTime(e.detail);
}, false)

const api = new alphaTab.AlphaTabApi(element);
</script>
```

### 变更后

事件监听器通过 `api.eventName.on(listener)` 注册。事件数据直接传递给监听器。

```html
<div id="alphaTab"></div>
<script type="module">
import * as alphaTab from '@coderline/alphaTab';
const element = document.querySelector('#alphaTab');
const api = new alphaTab.AlphaTabApi(element, settings);
api.error.on(error => {
    sendErrorToAnalytics(error);
});
api.playerPositionChanged.on(args => {
    updatePlayerTime(args);
});
</script>
```
