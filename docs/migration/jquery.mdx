> [!WARNING]
> 通过 DOM 事件监听 alphaTab 已在 1.5 版本中弃用，并将在 2.x 版本中移除。

jQuery 曾经是，现在仍然是 Web 开发领域的重要角色。对于 alphaTab，我们认为不再值得维护一个专门的 alphaTab jQuery 插件，因为 AlphaTabApi 对象已经提供了一个易于使用的接口，使得 jQuery 成为不必要的维护开销。

我们建议将所有代码库迁移到标准现代 JavaScript 和我们的 API 对象。

作为历史参考，本页面描述了如何使用 alphaTab jQuery 插件的一些方面，但请避免在新开发中使用它。


要在任何元素上初始化 alphaTab，请使用 `jQuery('.selector').alphaTab()`。初始化 alphaTab 后，您可以通过 `jQuery('.selector').alphaTab('api')` 访问 API 对象，或使用 API 接口的一个子集。参数和返回值可以相应传递。对于属性，如果未提供值，则加载当前值；如果提供了值，则设置该值。

* `jq.alphaTab('print')` - 委托给 [`api.print()`](/docs/reference/api/print.mdx)
