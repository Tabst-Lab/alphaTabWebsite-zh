## 我们要构建什么？
我们将构建一个将 alphaTab 所有主要方面连接在一起的组件。
结果类似于您可能在[首页](/)上已经看到的：

<img src="/img/tutorial-web/result.png" height="400" />

本教程的整体大纲可以在菜单中看到，我们将逐步
添加每个功能，直到我们拥有一个显示乐谱的完整播放器组件。
完成本教程后，您应该拥有在自己的
项目中使用 alphaTab 所需的所有知识。

本教程将省略首页演示中提供的一些功能，
但您将学到构建其余部分所需的一切。

## 先决条件

作为先决条件，您至少应该已经熟悉 HTML、JavaScript 和 CSS 等
Web 技术的基础知识。由于 alphaTab 是一个用于构建想要显示
乐谱的应用/网站的**库**（或者如果您喜欢，可以叫 **SDK**），因此需要具备软件开发的基本知识。

我们不会使用任何特殊的前端框架，如 React、Angular 或 Vue，但如果您已经熟悉这些
框架，那么应该很容易将本教程中展示的内容适配到您的需求中。

本教程将主要使用 ES6 语法特性，如果您需要支持旧版浏览器
（Internet Explorer，我在说你），您可能需要相应地更改语法或使用 Babel 等转译器来为您完成这项工作。

那么，让我们开始吧！:wink:
