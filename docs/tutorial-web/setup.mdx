---
title: 设置项目
---

首先，我们将为新组件搭建基础环境。为了简单起见，我们将所有代码放在一个 `index.html` 文件中。
我们还将使用内容分发网络（CDN）jsdelivr.net 将 alphaTab 引入到项目中，因此
不需要任何 Web 服务器。只需在您选择的浏览器中打开这个 `index.html` 文件，即可进行本教程的所有步骤。

如果您愿意，也可以将项目组织成单独的 JavaScript 和 CSS 文件。
为了本教程的简洁，我们将所有内容都放在一个文件中。

作为第一步，在任何文件夹中创建一个 `index.html` 文件，并在您选择的文本编辑器和浏览器中打开它。

<img src="/img/tutorial-web/project-setup-1.png" />

然后，我们将添加页面的基本框架并引入 alphaTab。将以下代码放入
您的 `index.html` 中。

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <title>AlphaTab Tutorial</title>
    <script src="https://cdn.jsdelivr.net/npm/@coderline/alphatab@latest/dist/alphaTab.js"></script>
    <style type="text/css">
      /* 我们的样式将放在这里 */
    </style>
  </head>
  <body>
    <div class="at-wrap">
      <!-- 我们的整个组件将放入这个包装器中 -->
    </div>
    <script type="text/javascript">
      // 我们的 JavaScript 代码将放在这里
    </script>
  </body>
</html>
```

但现在页面还是空的。在下一步中，我们将设置 alphaTab 并显示一些乐谱。
