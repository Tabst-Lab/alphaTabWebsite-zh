## 构建音轨选择器

alphaTab 支持的许多输入文件格式可以包含不止一种乐器。
可以有声乐、吉他、鼓或其他乐器的谱子，
用户希望在这些单独的音轨之间切换。

音轨选择器将放在侧边栏中，因此让我们用模板扩展我们的 `index.html`，
我们将使用该模板来创建音轨选择器中的所有项目，并在侧边栏中添加一些放置项目的位置。

让我们仔细看看这个新的 UI 元素。我们有一列用于音轨的图标，另一列用于音轨的详细信息。
在详细信息中，我们目前只显示音轨的名称。音量和静音的其他控件将在稍后添加。
在本教程中，我们使用 Font Awesome 来显示一些图标。

:::caution
不要使用本教程中的这个 Font Awesome CDN 链接。前往 https://fontawesome.com/
为您自己的网站创建个人工具包。
:::

现在真正的魔法发生了，因为我们将把它与 alphaTab 连接起来。我们将再次监听一些事件并相应地填充 UI。
这也是我们第一次使用 UI 交互来告诉 alphaTab 要做什么。
当用户点击某个项目时，我们希望渲染选定的音轨。

```js
// 创建单个项目的辅助函数
function createTrackItem(track) {
  const trackItem = document
    .querySelector("#at-track-template")
    .content.cloneNode(true).firstElementChild;
  trackItem.querySelector(".at-track-name").innerText = track.name;
  trackItem.track = track;
  trackItem.onclick = (e) => {
    e.stopPropagation();
    // 这里我们使用 alphaTab 的一些 API 函数。
    // 查看参考文档了解详细信息。
    api.renderTracks([track]);
  };
  return trackItem;
}


const trackList = wrapper.querySelector(".at-track-list");
// 当乐谱加载时填充音轨列表
api.scoreLoaded.on((score) => {
  // 清空项目
  trackList.innerHTML = "";
  // 为乐谱的所有音轨生成音轨项目
  score.tracks.forEach((track) => {
    trackList.appendChild(createTrackItem(track));
  });
});

// 将渲染的音轨在列表中标记为激活
api.renderStarted.on(() => {
  // 收集正在渲染的音轨
  const tracks = new Map();
  // 这里我们访问 alphaTab 当前渲染的音轨
  api.tracks.forEach((t) => {
    tracks.set(t.index, t);
  });
  // 将项目标记为激活或非激活
  const trackItems = trackList.querySelectorAll(".at-track");
  trackItems.forEach((trackItem) => {
    if (tracks.has(trackItem.track.index)) {
      trackItem.classList.add("active");
    } else {
      trackItem.classList.remove("active");
    }
  });
});
```

上面的代码应该很容易理解，但让我们仔细看看这里发生了什么。

我们有一个小的辅助函数，它为给定的音轨创建 DOM 元素。它使用之前的 `<template>`
元素来创建这个元素，然后我们只需填入名称。点击时，我们告诉 alphaTab 渲染给定的音轨。

在这个辅助函数下面，我们监听 [`scoreLoaded`](/docs/reference/api/scoreloaded) 事件，该事件在歌曲的数据模型加载完成后触发。
在那里，我们遍历每个音轨并为音轨选择器创建一个项目，将其放在侧边栏中。

最后，我们添加另一个对 [`renderStarted`](/docs/reference/api/renderstarted) 事件的监听器，该监听器用 CSS 类将侧边栏中当前渲染的
音轨标记为激活。
