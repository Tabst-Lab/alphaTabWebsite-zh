## 基本设置

既然我们已经准备好了基本组件，现在是时候添加一些声音了。
AlphaTab 自带一个名为 AlphaSynth 的音频合成引擎，用于通过 MIDI 和 SoundFont2/SoundFont3 文件播放乐曲。

配置播放器也非常简单：

1. 我们告诉 alphaTab 我们要启用播放器，并指定应该使用的 SoundFont 文件的位置。
alphaTab 提供了一个免费的 SoundFont 文件供您在网站上使用。
2. 我们告诉 alphaTab 当光标移动时要滚动哪个 DOM 元素。
3. 我们告诉 alphaTab 光标应该长什么样
4. 我们添加一些 UI 元素，让用户可以开始/暂停播放并显示当前位置。

## 加载指示器

就像 alphaTab 一样，alphaSynth 可能需要一些时间来初始化和加载所有必需的数据。
特别是 SoundFont 文件可能会变得相当大，可能需要一些时间来加载。因此我们将
在页脚添加一个小型加载指示器，以便用户知道播放器何时可以
使用。

最好为播放器设置一个单独的加载指示器。
典型的用户会在按下播放之前先看一会儿乐谱。
如果我们将乐谱的主加载指示器保持可见直到播放器准备就绪，用户就没有机会查看。

为了保持教程简单，我们只显示一个百分比值，但您可能希望在您的网站上显示一个好看的进度指示器。

[`playerReady`](/docs/reference/api/playerready.mdx) 将告诉我们何时隐藏指示器。

## 主播放器控件

现在我们需要添加用户播放和暂停音频所需的控件。
我们添加一个播放/暂停按钮，该按钮会根据当前播放状态改变图标。
我们还添加一个停止播放并将光标移回开头的按钮。

我们使用 [`playPause()`](/docs/reference/api/playpause) 和 [`stop()`](/docs/reference/api/stop) 向 alphaTab 发送正确的信号，并使用
[`playerStateChanged`](/docs/reference/api/playerstatechanged) 事件来更新按钮图标。为了确保用户在播放器准备就绪之前不会与之交互，
我们在播放器准备就绪之前保持按钮禁用状态。

    icon.classList.add("fa-pause");

  }

## 显示当前时间

在这一步中，我们将添加一个文本指示器来显示播放的当前位置。
您可以使用提供的信息为用户构建一个进度条指示器，
甚至可以支持交互式跳转，但本教程不会涵盖这些内容。

与大多数其他步骤一样，我们将添加一些新的 DOM 元素、相应的 CSS，然后
使用 alphaTab 事件 [`playerPositionChanged`](/docs/reference/api/playerpositionchanged) 将其连接起来，该事件提供必要的数据。

<TabItem value="js">

`playerPositionChanged` 事件触发得非常频繁。为了减少浏览器的压力，
我们将更新次数限制为每秒只更改一次。

```js
function formatDuration(milliseconds) {
  let seconds = milliseconds / 1000;
  const minutes = (seconds / 60) | 0;
  seconds = (seconds - minutes * 60) | 0;
  return (
    String(minutes).padStart(2, "0") +
    ":" +
    String(seconds).padStart(2, "0")
  );
}

const songPosition = wrapper.querySelector(".at-song-position");
let previousTime = -1;
api.playerPositionChanged.on((e) => {
  // 将 UI 更新次数减少到秒级变化。
  const currentSeconds = (e.currentTime / 1000) | 0;
  if (currentSeconds == previousTime) {
    return;
  }

  songPosition.innerText =
    formatDuration(e.currentTime) + " / " + formatDuration(e.endTime);
});
```
</TabItem>
</Tabs>
