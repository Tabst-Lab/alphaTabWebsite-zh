## 基本结构

随着本教程中我们的组件不断添加新的 UI 元素，我们已经提前准备好了
控件的粗略 DOM 结构。我们还希望我们的组件占据页面 80% 的
宽度和高度，并在此区域内滚动，所以让我们将文件更改为以下内容：

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <title>AlphaTab Tutorial</title>
    <script src="https://cdn.jsdelivr.net/npm/@coderline/alphatab@latest/dist/alphaTab.js"></script>
    <style type="text/css">
      .at-wrap {
        width: 80vw;
        height: 80vh;
        margin: 0 auto;
        border: 1px solid rgba(0, 0, 0, 0.12);
        display: flex;
        flex-direction: column;
        overflow: hidden;
        position: relative;
      }
      .at-content {
        position: relative;
        overflow: hidden;
        flex: 1 1 auto;
      }
      .at-sidebar {
        position: absolute;
        top: 0;
        left: 0;
        bottom: 0;
        max-width: 70px;
        width: auto;
        display: flex;
        align-content: stretch;
        z-index: 1001;
        overflow: hidden;
        border-right: 1px solid rgba(0, 0, 0, 0.12);
        background: #f7f7f7;
      }
      .at-viewport {
        overflow-y: auto;
        position: absolute;
        top: 0;
        left: 70px;
        right: 0;
        bottom: 0;
        padding-right: 20px;
      }
      .at-footer {
        flex: 0 0 auto;
        background: #436d9d;
        color: #fff;
      }
    </style>
  </head>
  <body>
    <div class="at-wrap">
      <div class="at-content">
        <div class="at-sidebar">
          音轨选择器将放在这里
        </div>
        <div class="at-viewport">
            <!-- 视口将滚动，at-main 将包含乐谱 -->
            <div class="at-main"></div>
        </div>
      </div>
      <div class="at-controls">
        播放器控件将放在这里
      </div>
    </div>
    <script type="text/javascript"></script>
  </body>
</html>
```

您已经可以看到控件的结构了。
这一步并不是 alphaTab 特有的，但从结构角度来看很重要。
我们正在构建一个带有侧边栏、主视口和页脚的布局。这个结构是通过
flexbox 和绝对定位的组合来实现的。CSS 网格可能更适合这里，但为了更好的
浏览器支持，我们坚持使用这些技术。

内容中的绝对定位将允许我们稍后构建一个动态扩展的侧边栏，
作为乐谱上的覆盖层。
在主视口上，我们还添加了一些内边距，为浏览器滚动条预留一些空间。

对于您的项目，您需要运用您的开发和设计技能来正确构建元素。
您需要考虑在哪里进行滚动（整页或在元素内），哪些控件
应该放在哪里（覆盖层、侧边栏等），并在此基础上构建您规划好的结构。

:::note

从现在开始，本教程可能只列出小的代码片段，具体取决于添加的更改。
每个教程部分的底部都会添加应用了所有更改的完整文件。

:::

## 初始化 alphaTab

现在让我们终于把 alphaTab 引入进来。但在初始化 alphaTab 之前，我们需要准备好一些输入
数据。在大多数情况下，您会有一个网站后端，知道要加载哪个输入文件来显示。
输入可以是任何支持的格式，如 Guitar Pro 文件或 alphaTex。
在本教程中，我们将使用 alphaTab 托管的演示文件 `https://www.alphatab.net/files/canon.gp`。

在包装器元素下方的 script 标签中，我们填入以下代码。
```html
<script type="text/javascript">
    // 加载元素
    const wrapper = document.querySelector(".at-wrap");
    const main = wrapper.querySelector(".at-main");

    // 初始化 alphatab
    const settings = {
      file: "https://www.alphatab.net/files/canon.gp",
    };
    const api = new alphaTab.AlphaTabApi(main, settings);
</script>
```

这段代码没有什么特别之处：

1. 首先我们选择要初始化 alphaTab 的 DOM 元素。
2. 然后我们创建一个设置对象，指定要显示的文件。
3. 然后我们创建一个新的 alphaTab API 对象。

最后一部分将直接触发文件的加载，并在视口中显示乐谱：

## 加载指示器

根据乐谱的大小，文件下载和渲染可能需要一段时间。
我们希望显示一个加载指示器，直到完成。这样，用户将直观地看到
文件正在加载和渲染。

为此，我们首先用遮罩层扩展 DOM，我们将根据
一些 alphaTab 事件动态显示和隐藏它。

目前，遮罩层始终可见。因此，让我们监听 alphaTab 的两个主要渲染事件，
[`renderStarted`](/docs/reference/api/renderstarted) 和 [`renderFinished`](/docs/reference/api/renderfinished)，
在渲染开始时显示遮罩层，并在渲染完成后隐藏它：

```js
// 遮罩层逻辑
const overlay = wrapper.querySelector(".at-overlay");
api.renderStarted.on(() => {
  overlay.style.display = 'flex';
});
api.renderFinished.on(() => {
  overlay.style.display = 'none';
});
```

现在我们已经有了 alphaTab 控件，显示输入文件并在加载时向
最终用户显示指示器。alphaTab 负责所有需要的工作，通过 Ajax 加载文件，渲染
乐谱并监听某些事件，例如调整大小以缩放
乐谱。

有一大堆设置允许您调整 alphaTab 的显示，
例如调整显示哪些元素、乐谱的布局方式、显示哪些音轨以及其他内部设置。
可以在[参考文档](/docs/reference/settings)中找到。
