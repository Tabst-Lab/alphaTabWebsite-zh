## 歌曲信息

为了填充歌曲信息，我们将再次订阅 [`scoreLoaded`](/docs/reference/api/scoreloaded) 事件，我们之前用它
来填充音轨选择器。然后我们只需选择占位元素并用
数据模型中的适当值填充它们：

```js
api.scoreLoaded.on((score)=>{
  wrapper.querySelector('.at-song-title').innerText = score.title;
  wrapper.querySelector('.at-song-artist').innerText = score.artist;
});
```

## 预备拍和节拍器

预备拍和节拍器将在下一步激活播放器时变得相关，但我们
已经可以创建控件，根据它们的切换按钮状态设置音量：

```js
const countIn = wrapper.querySelector('.at-controls .at-count-in');
countIn.onclick = () => {
  countIn.classList.toggle('active');
  if (countIn.classList.contains('active')) {
    api.countInVolume = 1;
  } else {
    api.countInVolume = 0;
  }
};

const metronome = wrapper.querySelector('.at-controls .at-metronome');
metronome.onclick = () => {
  metronome.classList.toggle('active');
  if (metronome.classList.contains('active')) {
    api.metronomeVolume = 1;
  } else {
    api.metronomeVolume = 0;
  }
};
```

我们切换 `active` CSS 类作为功能是否激活的视觉指示。
然后我们检查视觉状态来告诉 alphaTab 功能是否应该激活，通过分别设置
[`countInVolume`](/docs/reference/api/countinvolume) 和 [`metronomeVolume`](/docs/reference/api/metronomevolume) 值。

## 循环播放

类似于预备拍和节拍器，我们使用 `active` 类来决定
是否使用 [`isLooping`](/docs/reference/api/islooping) 选项激活循环播放。
这也只有在启用播放器功能后才会相关：

```js
const loop = wrapper.querySelector('.at-controls .at-loop');
loop.onclick = () => {
  loop.classList.toggle('active');
  api.isLooping = loop.classList.contains('active');
};
```

## 打印

有时用户可能想要打印乐谱或将其保存为 PDF。
由于 alphaTab 执行的动态渲染，简单的浏览器中按 CTRL+P 可能无法
获得所需的结果。整个乐谱通常在后台渲染，并且
有一些特殊功能只显示视口中的可见部分。

使用默认浏览器打印时，您可能只会看到一片空白。alphaTab API 提供了
一个 `print` 函数，它优化了打印渲染并在弹出窗口中打开它。

```js
wrapper.querySelector('.at-controls .at-print').onclick = () => {
  api.print();
};
```

## 缩放

由于 alphaTab 可以更改乐谱渲染的缩放比例，我们为用户提供
一个选择框来更改此比例。

```js
const zoom = wrapper.querySelector('.at-controls .at-zoom select');
zoom.onchange = ()=>{
  const zoomLevel = parseInt(zoom.value) / 100;
  api.settings.display.scale = zoomLevel;
  api.updateSettings();
  api.render();
};
```

更新缩放级别比之前的任务稍微复杂一些，但仍然不太复杂：
首先我们用新的缩放比例填充设置。然后我们告诉 alphaTab 加载这些更新后的设置
并重新渲染乐谱。

## 布局

alphaTab 可以以页面样式渲染乐谱，沿着可用宽度从上到下
增长，也可以以水平滚动方式显示乐谱。

这些选项也通过选择框提供给用户。要应用用户选择，
我们将用户输入转发到设置对象并触发更新，就像我们对
缩放级别所做的那样：

```js
const layout = wrapper.querySelector('.at-controls .at-layout select');
layout.onchange = () => {
  switch (layout.value) {
    case 'horizontal':
      api.settings.display.layoutMode = alphaTab.LayoutMode.Horizontal;
      break;
    case 'page':
      api.settings.display.layoutMode = alphaTab.LayoutMode.Page;
      break;
  }
  api.updateSettings();
  api.render();
};
```
