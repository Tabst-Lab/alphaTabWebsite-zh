自 alphaTab v1.1 起，你可以根据加载歌曲的需要将多个音色库加载到 alphaTab 中。本指南将向你展示如何设置 alphaTab，
使其仅根据加载的乐谱所需的音色库从服务器加载单个音色库。


:::note 太长不看
在 `scoreLoaded` 事件中检测你的轨道需要哪些 midi 程序，通过 Ajax 手动加载音色库，并使用
 `api.loadSoundFont(data, true)`，第二个参数设置为 true，将多个音色库加载到合成器中以进行播放。
:::

## 数据准备

首先，我们需要将音色库切分成更小的块。我们将使用 [Polyphone](https://www.polyphone-soundfonts.com/)
一个免费的音色库编辑器来完成此操作。

切分的合理性在很大程度上取决于你计划向用户提供什么样的音乐作品。
为了简化，在此示例中，我们将仅将音色库切分为 2 个文件：

1. sonivox-main.sf2 包含所有吉他（midi 24-31）和鼓
2. sonivox-others.sf2 包含其他文件

你当然可以走得更远，将每种乐器放入一个单独的文件中。一首典型的音乐作品通常
不会包含超过 4-5 种不同的乐器，这应该仍然允许快速下载文件。
现代浏览器限制了对服务器的并发请求数量，因此你可能会减慢数据加载速度。

首先，我们制作主音色库文件的 2 个副本，并按上述方式重命名它们。

<img src="/img/guides/multiple-soundfonts/files.png" />

然后我们在 Polyphone 中打开第一个文件，并选择除 000:24-000:31 和 128:000 之外的所有预设，右键单击它们并请求删除：

<img src="/img/guides/multiple-soundfonts/delete.png" />

之后，我们从乐器中清除所有未在预设中使用的条目。
这非常简单，我们可以选择 **所有** 乐器并请求删除，Polyphone 不会删除正在使用的那些

<img src="/img/guides/multiple-soundfonts/delete-instruments.png" />

我们对采样组执行相同的操作，选择所有并点击删除。之后你可以保存文件。

对于第二个文件，我们执行相反的操作：我们删除预设 000:24-000:31 和 128:000 并保留其余部分。

## 设置 alphaTab

现在我们需要接入一些 alphaTab 事件，以便在需要时加载正确的音色库。
下面的示例将为你提供一些关于如何管理下载的提示。

```html
<div>进度 <span id="progressValue">0%</div>
<button id="playPause" disabled="disabled">播放/暂停</button>
<div id="alphaTab"></div>
<script type="text/javascript">
	const el = document.querySelector('#alphaTab');
	const playPause = document.querySelector('#playPause');
	const at = new alphaTab.AlphaTabApi(el, {
		file: 'guitar-only.gp',
		player: {
			enablePlayer: true
		}
	});			
	playPause.onclick = e => {
		e.preventDefault();
		at.playPause();
	};
	
	
	const progress = new Map();
	function updateLoadingIndicator() {
		let loaded = 0;
		let total = 0;
		progress.forEach(value => {
			loaded += value.loaded;
			total += value.total;
		});
	
		document.querySelector('#progressValue').innerText = Math.floor( (loaded / total) * 100 ) + '%';
		if(total === loaded) {
			playPause.removeAttribute('disabled');
		}
	}
	
	function loadSoundFont(url) {
		// 只加载一次
		if(progress.has(url)) {
			return; 
		}
		
		// 在实际知道之前，假设平均大小为 100KB。
		progress.set(url, { loaded: 0, total: 100 * 1024});
	
		// 通过 ajax 加载
		const request = new XMLHttpRequest();
		request.open('GET', url, true);
		request.responseType = 'arraybuffer';
		request.onload = () => {
			const buffer = new Uint8Array(request.response);
			at.loadSoundFont(buffer, true);
		};
		request.onprogress = e => {
			progress.set(url, e);
			updateLoadingIndicator();
		};
		request.send();
	}			
	
	// 当乐谱加载时，根据程序触发音色库的加载。
	at.scoreLoaded.on(score => {
		score.tracks.forEach(track => {
			const program = track.playbackInfo.program;
			if(track.playbackInfo.primaryChannel === 9 /* 鼓 */ || (program >= 24 && program <= 31)) {
				loadSoundFont('sonivox-main.sf2');
			} else {
				loadSoundFont('sonivox-others.sf2');
			}
		});
	});
</script>
```

让我们回顾一下我们在这里做什么。首先，我们设置 alphaTab 启用播放器，但尚未配置音色库。
然后我们添加一个 `scoreLoaded` 事件的处理程序，当新的音乐作品加载时触发。然后我们将检查
各个轨道的 midi 程序，并动态启动音色库的加载。

音色库加载器使用 `Map` 来避免多次加载音色库并跟踪整体下载进度。
简而言之：`loadSoundFont` 在需要时加载音色库，报告进度，并在下载完成后启动 alphaTab 中的音色库加载。
重要的方面是 `loadSoundFont` 的第二个参数，它指示应添加音色库的预设，而不是替换。

如果我们用两个不同的文件检查逻辑，一个只有吉他，另一个混合了乐器，我们可以看到只加载了所需的音色库。
