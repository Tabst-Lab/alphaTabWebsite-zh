本指南介绍如何在无法使用或不需使用完整 API 对象的情况下使用 alphaTab 的底层 API。

完整的 API 对象通常通过 `IUiFacade` 直接链接到 UI。存在各种 `IUiFacade` 实现
用于不同的平台，如 Web、.net WPF 和 .net WinForms。

在以下场景中，你将需要使用底层 API 手动设置各个步骤：当这些 UI 平台都未使用，或者甚至没有 UI 时。以下示例展示了
使用 alphaTab 时你可能需要的最典型场景。

## 通过 ScoreLoader 加载文件

最常见的任务之一是从二进制缓冲区加载 `Score` 对象，
`AlphaTab.Importer.ScoreLoader` 类提供了一种简单的机制，接受一个缓冲区，
并尝试使用可用的导入器加载它。
在内部，alphaTab 有一个针对不同文件格式的 `ScoreImporter` 实现列表，
它们会依次尝试将提供的缓冲区解析为 `Score` 对象。如果缓冲区无法转换，
将抛出 `AlphaTab.Importer.UnsupportedFormatError`。

`LoadScoreFromBytes` 方法接受第一个参数为原始字节缓冲区，第二个可选参数为
`AlphaTab.Settings` 对象，它可能控制导入序列的某些方面。

<Tabs
  defaultValue="js"
  values={[
    { label: 'JavaScript', value: 'js', },
    { label: 'C#', value: 'cs', }
  ]
}>
<TabItem value="js">

```js
const xhr = new XMLHttpRequest();
xhr.open('GET', 'MyFile.gp', true);
xhr.responseType = 'arraybuffer';
xhr.onload = () => {
    const data = new Uint8Array(xhr.response);
    const settings = new alphaTab.Settings();
    let score: Score = alphaTab.importer.ScoreLoader.loadScoreFromBytes(data, settings);
};
xhr.send();
```

</TabItem>
<TabItem value="cs">

```cs
var data = System.IO.File.ReadAllBytes('MyFile.gp'); 
var settings = new AlphaTab.Settings();
var score = AlphaTab.Importer.ScoreLoader.LoadScoreFromBytes(data, settings);
```

## 通过 ScoreRenderer 渲染文件

`AlphaTab.Rendering.ScoreRenderer` 是主要组件，它接受 `Score` 和 `Settings` 作为输入，
然后生成渲染的乐谱。设置 `ScoreRenderer` 相当简单，如果你了解以下基础知识：

1. 如果你使用从上到下布局，ScoreRenderer 需要知道目标宽度
2. 乐谱以单独的块渲染，通过事件 `partialRenderFinished` 和 `renderFinished` 提供
3. AlphaTab 在使用 `renderScore` 渲染时内部保留有关已渲染乐谱的信息，之后可以通过 `resizeRender` 进行优化渲染和调整大小

ScoreRenderer 默认不提供在后台工作线程（即线程）中渲染。
此逻辑属于 `AlphaTabApi`，它将 ScoreRenderer 包装到工作线程中。

<Tabs
  defaultValue="js"
  values={[
    { label: 'JavaScript', value: 'js', },
    { label: 'C#', value: 'cs', }
  ]
}>
<TabItem value="js">

```js
// 1. 设置渲染器
const score = /* 在此处加载乐谱 */;
const settings = new alphaTab.Settings();
settings.core.engine = 'svg';
const renderer = new alphaTab.rendering.ScoreRenderer(settings);
renderer.width = 1200;

// 2. 监听事件
let svgChunks = [];
renderer.preRender.on(isResize => {
    svgChunks = []; // 在新渲染时清除
});
// 自 1.2.3 起，我们需要请求
// 渲染每个布局好的块。
// 你可以根据你的需要推迟渲染。
renderer.partialLayoutFinished.on(r => {
    renderer.renderResult(r.id);
});
renderer.partialRenderFinished.on(r => {
    svgChunks.push({
        svg: r.renderResult, // svg 字符串
        width: r.width,
        height: r.height
    });
});
renderer.renderFinished.on(r => {
    displayResult(svgChunks, r.totalWidth, r.totalHeight);
});

// 3. 开始渲染
renderer.renderScore(score, [0]);

// 4. 调整大小
renderer.width = 800;
renderer.resizeRender();
```

</TabItem>
<TabItem value="cs">

```cs
// 1. 设置渲染器
var score = /* 在此处加载乐谱 */;
var settings = new AlphaTab.Settings();
settings.Core.Engine = "svg";
var renderer = new AlphaTab.Rendering.ScoreRenderer(settings);
renderer.Width = 1200;

// 2. 监听事件
var svgChunks = new List<(string svg, double width, double height)>();
renderer.PreRender.On(isResize => {
    svgChunks.Clear(); // 在新渲染时清除
});
// 自 1.2.3 起，我们需要请求
// 渲染每个布局好的块。
// 你可以根据你的需要推迟渲染。
renderer.PartialLayoutFinished.On(r => {
    renderer.RenderResult(r.Id);
});
renderer.PartialRenderFinished.On(r => {
    svgChunks.Add((
        svg: (string)r.RenderResult, // svg 字符串
        width: r.Width,
        height: r.Height
    ));
});
renderer.RenderFinished.On(r => {
    DisplayResult(svgChunks, r.TotalWidth, r.TotalHeight);
});

// 3. 开始渲染
renderer.RenderScore(score, new List<double> { 0 });

// 4. 调整大小
renderer.Width = 800;
renderer.ResizeRender();
```

## 通过 MidiFileGenerator 生成 Midi 文件

AlphaTab 具有将 `Score` 对象转换为 `MidiFile` 的组件，
然后可以将其传递给其他组件以写入文件或输入到
Midi 合成引擎。与 midi 生成相关的主要类有：

1. `AlphaTab.Midi.MidiFileGenerator`，它包含使用 `IMidiFileHandler` 为 `Score` 发出正确 midi 事件的所有逻辑
2. `AlphaTab.Midi.AlphaSynthMidiFileHandler`，它用事件填充 `AlphaTab.Midi.MidiFile` 对象。
3. `AlphaTab.Midi.MidiFile` 表示可以传递给 AlphaSynth 或写入文件的 Midi 事件序列。

<Tabs
  defaultValue="js"
  values={[
    { label: 'JavaScript', value: 'js', },
    { label: 'C#', value: 'cs', }
  ]
}>
<TabItem value="js">

```js
const score = /* 在此处加载乐谱 */;
const settings = new alphaTab.Settings();

// 设置生成器和 midi 文件处理器
const midiFile = new alphaTab.midi.MidiFile();
const handler = new alphaTab.midi.AlphaSynthMidiFileHandler(midiFile, true /* 用于 SMF1.0 导出 */);
const generator = new alphaTab.midi.MidiFileGenerator(score, settings, handler);

// 开始生成
generator.generate();

// 使用 midi 文件
saveToFile(midiFile);
```

</TabItem>

```cs

// 开始生成

// 使用 midi 文件
```

## 通过 AlphaSynth 播放文件

Midi 文件本身并不是很有趣，但当你能播放它时，它就会变得有趣。
AlphaTab 有一个名为 AlphaSynth 的组件，它是一个基于 SoundFont2 的 midi 合成器。
它可以获取一个 SoundFont2 文件和一个由 alphaTab 生成的 Midi 文件，并在
通过 `IOutput` 实现的相应目标平台上播放它。

以下示例展示了如何使用主要组件 `AlphaSynth`，它通常在工作线程或线程中运行
以确保流畅播放。

<Tabs
  defaultValue="js"
  values={[
    { label: 'JavaScript', value: 'js', },
    { label: 'C#', value: 'cs', }
  ]
}>
<TabItem value="js">

```js
const midifile = /* 在此处加载乐谱并将其转换为 midi */;
const soundFont = /* 在此处加载 SoundFont2 为 Uint8Array */;

// 设置播放器
const player = new alphaTab.synth.AlphaSynth(
    new AlphaSynthWebAudioOutput() // 要使用的输出
);
player.loadSoundFont(soundFont);
player.loadMidiFile(midiFile);
player.play();
```

对于 Web 版本的 alphaTab，提供了一个开箱即用的实现
用于在 WebWorker 中操作 alphaSynth，并通过 Web Audio API 在浏览器主线程上播放音频：
`alphaTab.synth.AlphaSynthWebWorkerApi`。
API 与普通的 `AlphaSynth` 对象相同，但
在创建时需要更多输入，但之后其余部分的工作方式如上所述。

```js
const supportsAudioWorklets: boolean = window.isSecureContext && 'AudioWorkletNode' in window;

const player = new alphaTab.synth.AlphaSynthWebWorkerApi(
    // 在浏览器主线程上要使用的输出
    supportsAudioWorklets ? new alphaTab.synth.AlphaSynthAudioWorkletOutput() : new alphaTab.synth.AlphaSynthWebAudioOutput(),
    pathToAlphaSynthScriptFile, // 此脚本将用于启动工作线程，必须指向包含 alphaTab 的主文件
    alphaTab.LogLevel.Info // 要使用的日志级别
);
player.loadSoundFont(soundFont);
player.loadMidiFile(midiFile);
player.play();

```

## 将数据模型序列化为/从 JSON 序列化

alphaTab 可以将数据模型（以及设置对象）转换为 `Map` 对象，以便进一步
通过 JSON 序列化或通过线路传输。alphaTab 的普通数据模型需要连接许多引用
并且还需要创建正确的对象实例。此图不能简单地通过例如 `JSON.stringify` 写入 JSON，而需要
正确的逻辑来执行此操作。

:::note

序列化的 JSON/Map 不应用于将数据模型持久化到磁盘或数据库以供以后加载。
该格式不能保证与不同的 alphaTab 版本兼容，并且可能会随时间变化。
此数据结构可用于使用相同版本 alphaTab 的组件之间传输数据模型，如
后端+前端。

:::

此逻辑可以通过 `alphaTab.model.JsonConverter` 类访问。它为 `Score` 和 `Settings` 对象提供 4 个主要操作：

1. `*ToJsObject` - 将 `Score` 或 `Settings` 对象转换为 `Map` 结构以进行进一步序列化
2. `jsObjectTo*` - 将 `Map` 结构转换回 `Score` 或 `Settings` 对象。
3. `*ToJson` - 将 `Score` 或 `Settings` 对象转换为 JSON 编码字符串（仅限 Web）。
4. `jsonTo*` - 将 JSON 编码字符串转换回 `Score` 或 `Settings` 对象（仅限 Web）。

对于转换回 `Score` 对象，可以/应该传递一个 `Settings` 对象。

<Tabs
  defaultValue="js"
  values={[
    { label: 'JavaScript', value: 'js', },
    { label: 'C#', value: 'cs', }
  ]
}>
<TabItem value="js">

```js
const map = alphaTab.model.JsonConverter.scoreToJsObject(api.score);
const json = alphaTab.model.JsonConverter.scoreToJson(api.score);
const score = alphaTab.model.JsonConverter.jsObjectToScore(map, api.settings);
const json = alphaTab.model.JsonConverter.jsonToScore(json, api.settings);
```
