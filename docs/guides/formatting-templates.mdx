在页面布局中，alphaTab 将歌曲信息直接显示为乐谱的一部分。
此歌曲信息的显示可以通过 3 种方式调整：

* 颜色可以通过 `style` 调整（参见 [为乐谱着色](./coloring.mdx)）
* 对齐方式和文本模板可以通过 `style` 调整。
* 字体可以通过 [`settings.display.resources`](/docs/reference/settings/display/resources) 调整

这些机制目前在历史上有些分散。在 alphaTab 2.x 中，我们计划整合这些选项。

对于某些格式（如 Guitar Pro），alphaTab 会读取文件中包含的信息并调整对齐方式和模板。
无论如何，歌曲信息可以通过在加载后更新设置和数据模型来调整。

此处的示例使用 TypeScript 编写（为了类型清晰），相同的方法和属性在所有 alphaTab 版本中都可用。
何时以及设置什么样式取决于你的需求。你可能有一个应用于所有文件的自定义样式，或者你将样式存储在
文件旁边，并随文件一起加载。

最重要的部分须知：

* [`alphaTab.model.Score`](/docs/reference/types/model/score) 上的 [`style`](/docs/reference/types/model/score#style) 用于调整视觉元素的样式。
* [`alphaTab.model.ScoreStyle`](/docs/reference/types/model/scorestyle/) 上的 [`headerAndFooter`](/docs/reference/types/model/scorestyle#headerandfooter) 用于调整页眉和页脚元素的文本、可见性和对齐方式。
* `alphaTab.model.ScoreStyle` 上的 [`colors`](/docs/reference/types/model/elementstyle#colors) 用于调整页眉和页脚元素（及其他）的颜色。
* [`alphaTab.model.ScoreSubElement`](/docs/reference/types/model/scoresubelement) 定义了可样式化的元素列表（并非所有都与歌曲信息相关）

`template` 是一个字符串，可以具有以下占位符，然后替换为歌曲的相应信息：

* `%TITLE%`
* `%SUBTITLE%`
* `%ARTIST%`
* `%ALBUM%`
* `%WORDS%`
* `%WORDSMUSIC%`
* `%MUSIC%`
* `%TABBER%`
* `%COPYRIGHT%`
