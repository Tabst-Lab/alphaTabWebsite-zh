---
title: 播放器样式
---

AlphaTab 有一些与播放器相关的元素，可以通过 CSS 进行调整。元素描述和相应的 CSS 类可以在本页找到。
可以在 [主页](/) 找到所有样式激活的完整示例。

## 选择 (at-selection)

如果启用，用户可以用鼠标选择 alphaTab 的播放范围。AlphaTab 将生成一个附加了 CSS 类 `at-selection` 的 div 元素。
在此 div 中创建选择的各个部分。通常将一些透明的背景颜色附加到 div 上以直观地指示选择
而不隐藏任何内容。

```css
.at-selection div {
    background: rgba(64, 64, 255, 0.1);
}
```

![选择](/img/guides/styling/at-selection.png)

## 小节光标 (at-cursor-bar)

播放期间，alphaTab 将在当前播放小节的区域放置一个 div 元素。此 div 元素被分配 CSS 类 `at-cursor-bar`。
通常将一些透明的背景颜色附加到 div 上以直观地指示播放的小节而不隐藏任何内容。

```css
.at-cursor-bar {
    background: rgba(255, 242, 0, 0.25);
}
```

![小节光标](/img/guides/styling/at-cursor-bar.png)
      
## 拍光标 (at-cursor-beat)

播放期间，alphaTab 将在当前播放拍的区域放置一个 div 元素，并相应地对其进行动画处理以指示正在进行的播放。此 div 元素被分配 CSS 类 `at-cursor-beat`。还应指定光标的宽度，否则它可能不可见。

```css
.at-cursor-beat {
    background: rgba(64, 64, 255, 0.75);
    width: 3px;
}
```

![拍光标](/img/guides/styling/at-cursor-beat.png)
      
## 当前播放的元素 (at-highlight)

此功能仅在 alphaTab 在浏览器中渲染为 SVG 时可用。播放期间，alphaTab 会将 CSS 类 `at-highlight` 附加到所有与播放拍相关的 SVG 组。
在这种情况下，CSS 规则与 SVG 相关，通常应同时指定 `fill` 和 `stroke` 以确保
所有元素都被着色。根据 SVG 元素（线条、路径等），它们可能具有 fill 或 stroke。

```css
.at-highlight * {
    fill: #0078ff;
    stroke: #0078ff;
}
```
