JavaScript 版本的 alphaTab 主要针对浏览器中的使用进行了优化。至少顶层 `AlphaTabApi`
是 alphaTab 的 UI 聚焦接口。但 alphaTab 也可以在其他
JavaScript 环境中使用，如 Node.js 或无头 JavaScript 引擎。alphaTab 的核心是平台独立的
并且只需要某些 API 可用。使用 [alphaSkia](https://github.com/CoderLine/alphaSkia) 你甚至可以
生成光栅图形输出。

在本指南中，我们将设置一个 Node.js 示例，使用 alphaTab 将给定的输入文件渲染为 SVG 和 PNG。

## 1. 设置项目

开始非常简单：

1. 在新目录中运行 `npm init`
2. 运行 `npm install @coderline/alphatab` 安装 alphaTab
3. 创建一个新的 `index.mjs`，我们的代码将放在其中。

## 2. 基本代码结构

在我们的代码中，我们将首先加载 alphaTab 并从给定的输入文件路径加载 `Score`：

```js
// 加载 alphaTab
import * as alphaTab from "@coderline/alphatab";
// 文件加载所需
import * as fs from 'fs';

// 加载文件
const fileData = await fs.promises.readFile(process.argv[2]);
const settings = new alphaTab.Settings();
const score = alphaTab.importer.ScoreLoader.loadScoreFromBytes(
  new Uint8Array(fileData),
  settings
);
console.log(score.title);
```

当我们在命令行上运行此文件时，我们已经有了一个加载的数据模型：

## 3. 使用底层 API

从这一点开始，我们将使用底层 API 将乐谱渲染为 SVG。
到目前为止，alphaTab 没有附带任何允许渲染到
光栅图形的渲染引擎，因此我们将把它渲染为 SVG。如果你有
项目的特殊需求，欢迎在 [GitHub 上发起新的讨论](https://github.com/CoderLine/alphaTab/discussions)。

下面的代码主要取自 [底层 API 指南](/docs/guides/lowlevel-apis)。

```js
// 加载 alphaTab
import * as alphaTab from "@coderline/alphatab";
// 文件加载所需
import * as fs from 'fs';

// 1. 加载文件
const fileData = await fs.promises.readFile(process.argv[2]);
const settings = new alphaTab.Settings();

const score = alphaTab.importer.ScoreLoader.loadScoreFromBytes(
  new Uint8Array(fileData),
  settings
);

// 2. 设置渲染器
settings.core.engine = "svg";
const renderer = new alphaTab.rendering.ScoreRenderer(settings);
renderer.width = 1200;

// 3. 监听事件
let svgChunks = [];

// 新渲染时清除
renderer.preRender.on((isResize) => {
  svgChunks = []; 
});

// 自 1.3.0 起：
// alphaTab 将单个结果的"布局"和"渲染"分开。
// 在这种情况下，我们想要直接渲染任何部分布局好的
// （在 UI 场景中，渲染可能会推迟到部分可见时）
// 或者可以将 settings.core.enableLazyLoading 设置为 false。
renderer.partialLayoutFinished.on((r) => {
    renderer.renderResult(r.id);
})

// 每当部分渲染完成时，我们记住所有单独的输出。
renderer.partialRenderFinished.on((r) => {
  svgChunks.push({
    svg: r.renderResult, // svg 字符串
    width: r.width,
    height: r.height,
  });
});

// 4. 开始渲染，这是同步的，因此我们可以假设在此调用后所有结果都可用。
renderer.renderScore(score, [0]);

// 5. 输出 SVG 块
console.log(svgChunks.map((c) => c.svg).join("\n"));
```

## 4. CSS 依赖

渲染的 SVG 假设某些 CSS 特定部分可用于音乐字体。通常 alphaTab 会添加
一个 `style` 标签到页面，通过 Web 字体加载音乐符号字体（Bravura）。没有这些
样式，SVG 将无法正确显示符号。

相关的 CSS 模板是：

```css
@font-face {
    font-family: 'alphaTab';
        src: url('path-to-font/Bravura.eot');
        src: url('path-to-font/Bravura.eot?#iefix') format('embedded-opentype')
            , url('path-to-font/Bravura.woff') format('woff')
            , url('path-to-font/Bravura.otf') format('opentype')
            , url('path-to-font/Bravura.svg#Bravura') format('svg');
        font-weight: normal;
        font-style: normal;
}
.at-surface * {
    cursor: default;
    vertical-align: top;
    overflow: visible;
}
.at {
    font-family: 'alphaTab';
    speak: none;
    font-style: normal;
    font-weight: normal;
    font-variant: normal;
    text-transform: none;
    line-height: 1;
    line-height: 1;
    -webkit-font-smoothing: antialiased;
    -moz-osx-font-smoothing: grayscale;
    font-size: 34px;
    overflow: visible !important;
}
```

## 5. PNG 渲染 <SinceBadge since="1.3.0" inline="true" />

虽然 SVG 对于某些用例可能不错，但在某些环境中使用 PNG 作为输出更容易处理。
[`alphaSkia`](https://github.com/CoderLine/alphaSkia) 是我们创建的围绕 [Skia](https://skia.org/) 的自定义包装器，以实现最佳的兼容性和一致的渲染
跨平台。

首先，我们需要通过 `npm install @coderline/alphaskia` 安装主 alphaSkia 库。
其次，我们需要在计划运行应用程序的操作系统上安装原生操作系统依赖项（skia 库）：

* `npm install @coderline/alphaskia-windows`
* `npm install @coderline/alphaskia-linux`
* `npm install @coderline/alphaskia-macos`

完成这些后，我们可以用以下部分更新我们的 alphaTab 代码：

1. 我们连接 alphaTab 和 alphaSkia 以启用光栅图形渲染。
2. 我们将计划使用的字体加载到 alphaSkia 中。
3. 我们更改渲染设置以使用我们的自定义字体生成 PNG。
3. 我们将所有单独的 PNG 组合成一个最终的 PNG 并保存它。


### 连接 alphaTab 和 alphaSkia

要启用 alphaSkia，我们可以调用 `alphaTab.Environment.enableAlphaSkia`，在其中传入 Bravura 字体数据以使音乐记谱字体可用。

```js
import * as alphaTab from '@coderline/alphatab';
import * as fs from 'fs';
import * as alphaSkia from '@coderline/alphaskia';

// 1. 初始化 alphaSkia
alphaTab.Environment.enableAlphaSkia(
  (await fs.promises.readFile('node_modules/@coderline/alphatab/dist/font/Bravura.ttf')).buffer /* 需要一个 ArrayBuffer */,
  alphaSkia
);
```

### 加载我们计划使用的字体。

我们想在 alphaTab 中使用一些自定义字体来显示普通文本，因此我们加载它们以供以后使用。

```js
import * as alphaTab from '@coderline/alphatab';
import * as fs from 'fs';
import * as alphaSkia from '@coderline/alphaskia';

// 1. 初始化 alphaSkia
alphaTab.Environment.enableAlphaSkia(
  (await fs.promises.readFile('node_modules/@coderline/alphatab/dist/font/Bravura.ttf')).buffer /* 需要一个 ArrayBuffer */,
  alphaSkia
);

// 2. 加载自定义字体
const fontFiles = [
  'font/roboto/Roboto-Regular.ttf',
  'font/roboto/Roboto-Italic.ttf',
  'font/roboto/Roboto-Bold.ttf',
  'font/roboto/Roboto-BoldItalic.ttf',
  'font/ptserif/PTSerif-Regular.ttf',
  'font/ptserif/PTSerif-Italic.ttf',
  'font/ptserif/PTSerif-Bold.ttf',
  'font/ptserif/PTSerif-BoldItalic.ttf',
];

const fontInfo = [];
for (const fontFile of fontFiles) {
  const fontData = await fs.promises.readFile(fontFile);
  fontInfo.push(alphaTab.Environment.registerAlphaSkiaCustomFont(new Uint8Array(fontData)));
}

// 3. 加载文件
const fileData = await fs.promises.readFile(process.argv[2]);
const settings = new alphaTab.Settings();
const score = alphaTab.importer.ScoreLoader.loadScoreFromBytes(
  new Uint8Array(fileData),
  settings
);
```

### 更改渲染设置以使用我们的自定义字体生成 PNG。

```js
import * as alphaTab from '@coderline/alphatab';
import * as fs from 'fs';
import * as alphaSkia from '@coderline/alphaskia';

// 1. 初始化 alphaSkia
alphaTab.Environment.enableAlphaSkia(
  (await fs.promises.readFile('node_modules/@coderline/alphatab/dist/font/Bravura.ttf')).buffer /* 需要一个 ArrayBuffer */,
  alphaSkia
);

// 2. 加载自定义字体
const fontFiles = [
  'path-to-fonts/roboto/Roboto-Regular.ttf',
  'path-to-fonts/roboto/Roboto-Italic.ttf',
  'path-to-fonts/roboto/Roboto-Bold.ttf',
  'path-to-fonts/roboto/Roboto-BoldItalic.ttf',
  'path-to-fonts/ptserif/PTSerif-Regular.ttf',
  'path-to-fonts/ptserif/PTSerif-Italic.ttf',
  'path-to-fonts/ptserif/PTSerif-Bold.ttf',
  'path-to-fonts/ptserif/PTSerif-BoldItalic.ttf',
];

const fontInfo = [];
for (const fontFile of fontFiles) {
  const fontData = await fs.promises.readFile(fontFile);
  fontInfo.push(alphaTab.Environment.registerAlphaSkiaCustomFont(new Uint8Array(fontData)));
}

// 3. 加载文件
const fileData = await fs.promises.readFile(process.argv[2]);
const settings = new alphaTab.Settings();
const score = alphaTab.importer.ScoreLoader.loadScoreFromBytes(
  new Uint8Array(fileData),
  settings
);

// 4. 设置渲染器
settings.core.engine = "skia"; // 请求 skia 渲染

const sansFontName = fontInfo[0].families;
const serifFontName = fontInfo[4].families;

settings.display.resources.copyrightFont.families = sansFontName;
settings.display.resources.titleFont.families = serifFontName;
settings.display.resources.subTitleFont.families = serifFontName;
settings.display.resources.wordsFont.families = serifFontName;
settings.display.resources.effectFont.families = serifFontName;
settings.display.resources.fretboardNumberFont.families = sansFontName;
settings.display.resources.tablatureFont.families = sansFontName;
settings.display.resources.graceFont.families = sansFontName;
settings.display.resources.barNumberFont.families = sansFontName;
settings.display.resources.fingeringFont.families = serifFontName;
settings.display.resources.markerFont.families = serifFontName;

const renderer = new alphaTab.rendering.ScoreRenderer(settings);
renderer.width = 1200;
```

### 将所有单独的 PNG 组合成一个最终的 PNG 并保存它。

这里变得有点棘手：要绘制最终图像，我们需要知道它的最终大小。

从技术上讲，我们可以收集所有部分结果并在最后绘制完整图像，但这可能会导致
相当多的内存消耗，因为所有部分都必须保留在内存中直到组合它们。但我们希望做得更好，通过
将任何部分直接绘制到最终图像中，然后清理该部分。

因此，我们不能在布局完成时直接请求绘制，而是首先等待布局完全完成以获得总大小。
然后我们请求所有部分进行渲染。此逻辑在以下部分中实现：


```js
import * as alphaTab from '@coderline/alphatab';
import * as fs from 'fs';
import * as alphaSkia from '@coderline/alphaskia';

// 1. 初始化 alphaSkia
alphaTab.Environment.enableAlphaSkia(
  (await fs.promises.readFile('node_modules/@coderline/alphatab/dist/font/Bravura.ttf')).buffer /* 需要一个 ArrayBuffer */,
  alphaSkia
);

// 2. 加载自定义字体
const fontFiles = [
  'font/roboto/Roboto-Regular.ttf',
  'font/roboto/Roboto-Italic.ttf',
  'font/roboto/Roboto-Bold.ttf',
  'font/roboto/Roboto-BoldItalic.ttf',
  'font/ptserif/PTSerif-Regular.ttf',
  'font/ptserif/PTSerif-Italic.ttf',
  'font/ptserif/PTSerif-Bold.ttf',
  'font/ptserif/PTSerif-BoldItalic.ttf',
];

const fontInfo = [];
for (const fontFile of fontFiles) {
  const fontData = await fs.promises.readFile(fontFile);
  fontInfo.push(alphaTab.Environment.registerAlphaSkiaCustomFont(new Uint8Array(fontData)));
}

// 3. 加载文件
const fileData = await fs.promises.readFile(process.argv[2]);
const settings = new alphaTab.Settings();
const score = alphaTab.importer.ScoreLoader.loadScoreFromBytes(
  new Uint8Array(fileData),
  settings
);

// 4. 设置渲染器
settings.core.engine = "skia"; // 请求 skia 渲染

const sansFontName = fontInfo[0].families;
const serifFontName = fontInfo[4].families;

settings.display.resources.copyrightFont.families = sansFontName;
settings.display.resources.titleFont.families = serifFontName;
settings.display.resources.subTitleFont.families = serifFontName;
settings.display.resources.wordsFont.families = serifFontName;
settings.display.resources.effectFont.families = serifFontName;
settings.display.resources.fretboardNumberFont.families = sansFontName;
settings.display.resources.tablatureFont.families = sansFontName;
settings.display.resources.graceFont.families = sansFontName;
settings.display.resources.barNumberFont.families = sansFontName;
settings.display.resources.fingeringFont.families = serifFontName;
settings.display.resources.markerFont.families = serifFontName;

const renderer = new alphaTab.rendering.ScoreRenderer(settings);
renderer.width = 1200;

// 5. 监听事件

// 新渲染时清除
let partialIds = [];
renderer.preRender.on((isResize) => {
  partialIds = []; 
});

// alphaTab 将单个结果的"布局"和"渲染"分开。在这种情况下，我们想要直接渲染任何部分布局好的
// （在 UI 场景中，渲染可能会推迟到部分可见时）
// 或者可以将 settings.core.enableLazyLoading 设置为 false。
renderer.partialLayoutFinished.on((r) => {
    partialIds.push(r.id);
});

// 由于 `renderFinished` 的历史行为，名称可能具有误导性。但此事件在歌曲布局完成且所有部分都可用并准备好渲染时触发。
// 不再有事件指示所有部分都已渲染。
const finalImageCanvas = new alphaSkia.AlphaSkiaCanvas();
renderer.renderFinished.on((r) => {
  finalImageCanvas.beginRender(r.totalWidth, r.totalHeight);
  // 仅为了在此演示中可见，我们用白色背景填充画布，但如果你愿意，可以保留透明
  finalImageCanvas.color = alphaSkia.AlphaSkiaCanvas.rgbaToColor(255, 255, 255, 255);
  finalImageCanvas.fillRect(0,0, r.totalWidth, r.totalHeight);

  for(const id of partialIds) {
    renderer.renderResult(id);
  }
});

// 每当部分渲染完成时，我们将其绘制到最终图像中。
renderer.partialRenderFinished.on((r) => {
  finalImageCanvas.drawImage(r.renderResult, r.x, r.y, r.width, r.height);

  // 释放部分图像并释放其使用的内存
  r.renderResult[Symbol.dispose]();
});

// 6. 开始渲染，这是同步的，因此我们可以假设在此调用后所有结果都可用。
renderer.renderScore(score, [0]);

// 7. 将最终图像保存为 png
const finalImage = finalImageCanvas.endRender();
const outputFilePath = process.argv[2] + '.png';
// 编码为 PNG 并释放最终图像的内存
const png = finalImage.toPng();
finalImage[Symbol.dispose]();
finalImageCanvas[Symbol.dispose]();
await fs.promises.writeFile(outputFilePath, new Uint8Array(png));
```
