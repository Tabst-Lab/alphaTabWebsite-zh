title: 处理 Midi 事件
---

## 简介

当 alphaTab 播放音频时，它在内部使用基于 Midi 和 SoundFont2 的合成器。
它播放的 midi 是从数据模型生成的，包括音符何时开始/停止播放的消息，
何时速度变化等。这些定时的 "Midi 消息" 被称为 "Midi 事件"。此外，还有 midi 事件用于
节拍器或预备拍声音等事件，这些事件将触发一个特殊音符的播放。

你可以在互联网上了解更多关于 midi 的信息，这里有一些进一步阅读的链接：

* https://www.midi.org/images/easyblog_articles/47/audio_midi.pdf
* https://www.midi.org/midi-articles/about-midi-part-3-midi-messages
* https://www.midi.org/midi-articles/about-midi-part-4-midi-files
* 官方规范：https://www.midi.org/specifications

在使用 alphaTab 构建应用程序或网站时，你可能需要在播放期间知道某些 midi 事件
已被处理和播放。最明显的例子是处理节拍器。你可能想要
显示节拍器的一些视觉反馈，比如一个数字直观地计数。但其他事件如
音符开始/停止播放也可能很重要。

alphaTab 公开了一个事件，你可以在其中注册已播放的 midi 事件。在内部，alphaTab
缓冲音频，因此它会首先处理一批 midi 事件并生成相关的音频。
一旦检测到这些事件实际上在音频设备上播放，alphaTab 中的事件将被触发
你可以在你的代码库中处理已播放的事件。

:::note
由于音频延迟和 alphaTab 的架构，你必须考虑到实际播放和事件触发之间可能存在延迟。此延迟可能取决于机器性能。
:::

:::note
其次，你必须注意到 midi 事件只是定时的单个事件，没有直接的持续时间。当播放一个音符时，
它没有 "在时间 X 播放音符，持续时间为 Y" 的事件。它有一个事件 "在时间 X 开始在通道 1 上播放键 90 的音符"，稍后
当音符应该停止时，有一个事件 "在时间 Y 停止在通道 1 上播放键 90 的音符"。你可以将其视为在键盘上，
按下键时，声音开始播放直到你释放它。此时还不知道持续时间。

你可以使用 [`midiLoad`](/docs/reference/api/midiload) 事件来检查合成器将加载的所有 midi 事件。
可以从跟踪相关事件中获得额外的值，如持续时间。
:::

## 动手实践

动手实践将侧重于如何使用 Web 版本开发此解决方案，但应该很容易将其应用于任何其他平台。

在以下动手实践中，我们将使用与已播放 midi 事件相关的主要 alphaTab 事件（到处都是事件！）来
构建一个视觉节拍器，它将以双重方式计数，如 "1 和 2 和 3 和 4"。

为了实现这一点，我们将遵循以下策略：

1. 我们将监听已播放的节拍器滴答声，以将节拍器计数器更新为 1,2,3 等等。
2. 我们将监听拍号事件，以便能够得出正确的计数和节拍器的持续时间。
3. 我们将监听速度变化，以便能够将 midi 节拍转换为实际的毫秒数。
4. 使用来自 2. 和 3. 的时间信息，我们将使用一个简单的 timeout 显示 "和" 标签。

### 简单计数器

首先，我们将添加代码来添加计数器。为此，我们将通过将其添加到过滤器并订阅
事件来监听 `SystemExclusive2` 事件。没有过滤器，事件将不会触发。出于性能原因，alphaTab 仅发出已注册的事件信号，而不是所有
已播放的事件。

```js
const el = document.getElementById('alphaTab');
let api = new alphaTab.AlphaTabApi(el);
api.metronomeVolume = 1;
api.playbackSpeed = 0.5;

document.getElementById('playPause').onclick = () => {
    api.playPause();
};

const counterSpan = document.getElementById('counter');
api.midiEventsPlayedFilter = [alphaTab.midi.MidiEventType.AlphaTabMetronome];
api.playerStateChanged.on(e => {
    // 停止时重置为 1
    if(e.stopped) {
        counterSpan.innerText = 1;
    }
});
api.midiEventsPlayed.on(e => {
    for (const midi of e.events) { // 遍历所有已播放的事件
        if (midi.isMetronome) { // 如果播放了节拍器，更新 UI
            counterSpan.innerText = midi.metronomeNumerator + 1;
        }
    }
});
```

### 添加 "和" 计数

这里变得有点棘手。alphaTab 不进行 "和" 计数。没有对应的事件。因此我们必须找出 "和" 开始的时间，
它应该在两个数字计数之间的中间。这意味着我们需要知道在正常节拍器事件之后多少毫秒
我们需要显示 "和"。幸运的是，对于节拍器事件，alphaTab 提供了这些详细信息。

```js
const el = document.getElementById('alphaTab');
let api = new alphaTab.AlphaTabApi(el);
api.metronomeVolume = 1;
api.playbackSpeed = 0.5;

document.getElementById('playPause').onclick = () => {
    api.playPause();
};

const counterSpan = document.getElementById('counter');
const andSpan = document.getElementById('and');

api.midiEventsPlayedFilter = [alphaTab.midi.MidiEventType.AlphaTabMetronome];

andSpan.style.display = 'none'; // 开始时隐藏 '和'
api.playerStateChanged.on(e => {
    // 停止时重置为 1
    if(e.stopped) {
        counterSpan.innerText = 1;
        andSpan.style.display = 'none';
    }
});
api.midiEventsPlayed.on(e => {
    for (const midi of e.events) { // 遍历所有已播放的事件
        if (midi.isMetronome) { // 如果播放了节拍器，更新 UI
            console.log('metronome');
            counterSpan.innerText = midi.metronomeNumerator + 1;
            andSpan.style.display = 'none'; // 在滴答时隐藏 '和'。
            // 在节拍器持续时间的一半后显示 "和"
            const andTime = (midi.metronomeDurationInMilliseconds / 2) / api.playbackSpeed;
            setTimeout(() => {
                andSpan.style.display = 'inline';
            }, andTime);
        }
    }
});
```

没什么特别的对吧？只是在给定的时间隐藏和显示一些 span。

<img src="/img/guides/handling-midi-events/and-counting.gif" />

现在由你以任何你可以使用的方式使用此功能。你可以订阅 midi 事件
并将它们转发到你喜欢的任何其他组件。请记住，订阅太多事件可能会
导致一些性能下降，并且由于存在一些音频延迟，可能会有一些延迟。
