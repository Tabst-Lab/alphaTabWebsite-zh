# 为乐谱着色

import { SinceBadge } from '@site/src/components/SinceBadge';

<SinceBadge since="1.5.0" />

alphaTab 支持通过特殊的 `style` 容器对音乐记谱元素进行单独的样式设置，该容器在
[数据模型](../reference/score.mdx) 的大多数级别上都可用。这意味着你可以根据自定义逻辑自定义渲染的单个音符的颜色。

应用自定义着色的最佳位置是 [`api.scoreLoaded`](../reference/api/scoreloaded.mdx) 事件，该事件在检测到新乐谱时触发。但你也可以在稍后随时通过访问 [`score`](../reference/api/score.mdx) 来修改样式，然后
通过 [`render`](../reference/api/render.mdx) 启动重新渲染。

:::important
alphaTab 不会动态检测对数据模型所做的任何更改。渲染发生在后台工作线程中，调用 `render` 将确保
所有更新的信息都传递给此渲染器，并更新显示。调用 `render` 将启动乐谱的完整重新布局和绘制
以相应地应用任何样式更改，因此这是一个相当耗费性能的操作。
:::

本指南中的示例代码使用 JavaScript，但可以相应地适应其他平台。

## 可样式化的元素

alphaTab 试图提供对音乐记谱元素着色的细粒度访问。只有在涉及单个效果和注释时，事情才会变得更粗略。

### 乐谱级别

在乐谱级别，初始化 `score.style = new alphaTab.model.ScoreStyle()`，然后通过 `alphaTab.model.ScoreSubElement` 选择要着色的元素。
