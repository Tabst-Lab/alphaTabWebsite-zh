alphaTab 可以与外部音频或视频伴奏同步。你可以使用带有音频轨道的 Guitar Pro 8 文件，或者使用
[Playground 中的媒体同步编辑器](/docs/playground/playground.mdx) 将 alphaTab 与外部媒体同步。

此时 alphaTab 无法将合成音频和伴奏混合在一起，因此只能听到其中一种音频。使用嵌入在数据模型中的同步信息，
当外部媒体接管音频时，alphaTab 可以正确放置光标。

### 音频伴奏

alphaTab 内置支持音频伴奏。要使用音频伴奏而不是合成音频播放 alphaTab，必须满足以下先决条件：

1. 数据模型包含伴奏音频文件。
2. 数据模型包含将外部音频轨道与音乐记谱对齐的同步点。
3. 你通过 `PlayerMode.EnabledAutomatic` 或 `PlayerMode.EnabledBackingTrack` 启用了伴奏。
4. 你的平台（浏览器、操作系统等）必须支持嵌入的音频文件。OGG Vorbis 和 MP3 得到了相当广泛的支持，如果使用，应该不会有重大问题。

要解决 1. 和 2.，你可以使用我们在 [Playground](/docs/playground/playground.mdx) 上提供的媒体同步编辑器。在此了解更多关于编辑器的信息 [here](./media-sync-editor.mdx)

### Guitar Pro 8 文件

自第 8 版起，Guitar Pro 提供内置音频轨道，可以将伴奏与乐谱同步。如果音频文件嵌入到 GP 文件中，alphaTab 可以加载和使用
音频文件和同步点信息。

如上所述，alphaTab 只能播放 **外部音频文件** **或** **合成音频**。我们也不支持音频中的更改（如调整音高）。

除此之外，你可以加载 Guitar Pro 8 文件，并直接从增强的声音体验中受益。

### 自定义外部媒体播放器

alphaTab 可以与任何外部媒体系统集成，但这需要集成器方面进行一些实现。要正确同步 alphaTab 和外部媒体源（音频或视频），必须实现并提供 `alphaTab.synth.IExternalMediaHandler` 接口给 alphaTab。
除此之外，alphaTab 必须被告知外部媒体上的时间更新（例如，在播放和跳转期间）。此更新应以小于两个连续音符的速率进行。50 毫秒的更新即使在快速歌曲上也显示效果良好，但为了节省电量和电池，你可能希望动态处理此问题。

以下示例说明了与 HTML 媒体元素（如 `<audio />` 或 `<video />`）的完整集成。这应该是如何实现与你的媒体播放器相关的同步的一个很好的参考。
大多数事情应该相当明显，如同步音量、播放速度和提供时间与持续时间。

#### YouTube

YouTube 是 alphaTab 的一个很好的搭档，可以为你的乐谱提供音频和视频。到目前为止，我们决定不直接集成 YouTube，因为这有一些影响。
背后的一些关键原因是：

1. alphaTab 是一个跨平台工具包。虽然在 Web 中集成 YouTube 播放器很容易，但 Android 或桌面平台的 SDK 要复杂得多。我们希望将此留给集成器处理。
2. 考虑到数据保护法（如 GDPR），用户必须接受此类外部媒体的加载和集成。我们希望确保开发者在需要时妥善征求用户同意。
3. YouTube 播放器的集成需要在用户界面中进一步考虑（大小、放置位置、如何配置 YouTube 播放器）。

尽管如此，我们还是想为你提供一些关于如何将 alphaTab 链接到 YouTube 的指导。以下步骤展示了如何使用 [YouTube 播放器 iframe 嵌入 API 参考](https://developers.google.com/youtube/iframe_api_reference) 与 alphaTab 一起使用。


```js
// 假设某处有一个 <div id="youtube"></div>


//
// 1. 加载 YouTube IFrame API。我们使用 promises 来更好地控制初始化顺序

const playerElement = document.getElementById('youtube');

const tag = document.createElement('script');
tag.src = "https://www.youtube.com/player_api";
playerElement.parentNode.insertBefore(tag, playerElement);

const youtubeApiReady = Promise.withResolvers();
window.onYouTubePlayerAPIReady = youtubeApiReady.resolve;

//
// 2. 已经初始化 alphaTab

const api = new alphaTab.AlphaTabApi('#alphaTab', {
    core: {
        file: 'my-synced-file.gp'
    },
    player: {
        // 设置外部媒体模式
        playerMode: alphaTab.PlayerMode.EnabledExternalMedia
    }
});
window.at = at;

//
// 3. 等待 youtube API 准备就绪
await youtubeApiReady.promise;


//
// 4. 设置 youtube 播放器并等待视频准备好播放
const youtubePlayerReady = Promise.withResolvers();
let currentTimeInterval  = 0;
const player = new YT.Player(playerElement, {
    height: '360',
    width: '640',
    videoId: 'your-video-id',
    playerVars: { 'autoplay': 0 }, // 我们不想要自动播放
    events: {
        'onReady': (e) => {
            youtubePlayerReady.resolve();
        },

        // 当播放器状态改变时，我们相应地更新 alphatab。
        'onStateChange': (e) => {
            // 
            switch (e.data) {
                case YT.PlayerState.PLAYING:
                    currentTimeInterval = window.setInterval(() => {
                        api.player.output.updatePosition(player.getCurrentTime() * 1000)
                    }, 50);
                    api.play();
                    break;
                case YT.PlayerState.ENDED:
                    window.clearInterval(currentTimeInterval);
                    api.stop();
                    break;
                case YT.PlayerState.PAUSED:
                    window.clearInterval(currentTimeInterval);
                    api.pause();
                    break;
                default:
                    break;
            }
        },
        'onPlaybackRateChange': (e) => {
            api.playbackSpeed = e.data;
        },
        'onError': (e) => {
            youtubePlayerReady.reject(e);
        },
    }
});

await youtubePlayerReady.promise;

// 
// 5. 设置处理程序，让 alphaTab 在需要时控制 youtube 播放器

// 使用 youtube 处理程序设置 alphaTab
const alphaTabYoutubeHandler = {
    get backingTrackDuration() {
        return player.getDuration() * 1000;
    },
    get playbackRate() {
        return player.getPlaybackRate();
    },
    set playbackRate(value) {
        player.setPlaybackRate(value);
    },
    get masterVolume() {
        return player.getVolume() / 100;
    },
    set masterVolume(value) {
        player.setVolume(value * 100);
    },
    seekTo(time) {
        player.seekTo(time / 1000);
    },
    play() {
        player.playVideo();
    },
    pause() {
        player.pauseVideo();
    }
};
api.player.output.handler = alphaTabYoutubeHandler;
```

正如你所见，这只是来回传递正确的调用和值的问题，就像使用 `<audio />` 元素一样。

> [!WARNING]
> YouTube IFrame API 在跳转方面有一个相当令人讨厌的行为：由于某些奇怪的原因，`seekTo` 会根据状态开始播放视频。
> 文档说：
> > `player.seekTo(seconds:Number, allowSeekAhead:Boolean):Void`
> >
> > 跳转到视频中的指定时间。如果调用函数时播放器处于暂停状态，它将保持暂停。如果从其他状态（播放、视频已缓存等）调用该函数，播放器将播放视频。
>
> alphaTab 最初可能会跳转到起始位置。这可能导致视频直接开始播放，而你可能不希望这样。
> 要解决此问题，你可以调整处理程序以检查播放器状态并做出相应反应。

```js
let initialSeek = -1;
const alphaTabYoutubeHandler = {
    get backingTrackDuration() {
        return player.getDuration() * 1000;
    },
    get playbackRate() {
        return player.getPlaybackRate();
    },
    set playbackRate(value) {
        player.setPlaybackRate(value);
    },
    get masterVolume() {
        return player.getVolume() / 100;
    },
    set masterVolume(value) {
        player.setVolume(value * 100);
    },
    seekTo(time) {
        if (
            player.getPlayerState() !== YT.PlayerState.PAUSED &&
            player.getPlayerState() !== YT.PlayerState.PLAYING
        ) {
            initialSeek = value / 1000;
        } else {
            player.seekTo(value / 1000);
        }
    },
    play() {
        player.playVideo();
        if (initialSeek >= 0) {
            player.seekTo(initialSeek);
            initialSeek = -1;
        }
    },
    pause() {
        player.pauseVideo();
    }
};
```
