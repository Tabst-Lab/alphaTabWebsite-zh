## 什么是 alphaTab？

**alphaTab** 是一个 JavaScript、.net 和 Android 库，用于构建乐谱软件和网站。它允许您使用各种支持的输入文件，将美观且功能丰富的乐谱嵌入到您的网站中。

截至目前，alphaTab **不是**一个开箱即用、提供所有功能的即插即用组件。您应该将其视为一个 **SDK** 或 **库**，以您需要的方式在网站中构建组件。对乐谱的需求因应用程序和网站而异。您需要一定的开发技能才能将 alphaTab 集成到解决方案中。

从高层次来看，alphaTab 可以分为以下子模块：

1. 数据模型
2. 文件导入器
3. 渲染引擎
4. 音频引擎

这 4 个模块共同构成了 alphaTab，使您能够在网站或应用程序中提供现代且交互式的乐谱功能。

## 兼容性

不同版本的 alphaTab 共享相同的源代码。
我们使用特殊的工具链将 TypeScript 代码编译为 C# 和其他语言。
这样所有平台都能受益于我们添加的新功能。未来我们计划将 alphaTab 扩展到更多平台，如原生 Android 和 iOS。

## 数据模型
数据模型保存了关于一首音乐的所有信息。这包括一般信息，如歌曲标题和艺术家，但也深入到单个音符级别。alphaTab 渲染或播放乐谱所需的一切都存储在这个数据模型中。

## 文件导入器
为了填充数据模型，alphaTab 使用所谓的`导入器`。市场上有各种可以保存乐谱信息的文件格式。alphaTab 的导入器支持：

* Guitar Pro 3-5 文件 `.gp3`、`.gp4`、`.gp5`，这是 [Arobas Music](https://www.guitar-pro.com/en/index.php?pg=about) 的专有二进制格式
* Guitar Pro 6 文件 `.gpx`，这是一种专有存档格式，将音乐信息存储为 XML
* Guitar Pro 7 文件 `.gp`，这是一种 zip 存档，将音乐信息存储为 XML
* [MusicXML](https://www.musicxml.com/) 文件 `.xml`，这是一个开放联盟制定的基于 XML 的开放标准
* [CapXML](https://www.capella.de/CapXML/) 文件 `.cap`，这是 Capella Software 制定的基于 XML 的开放标准
* [alphaTex](/docs/alphatex/introduction) 是一种基于文本的格式，优化了以文本格式编写乐谱的功能

## 渲染引擎
这个引擎使乐谱可见。alphaTab 获取存储在数据模型中的所有信息，并进行视觉布局和渲染，这被称为音乐雕版。

为此，alphaTab 构建了一个遵循音乐符号规则的所有符号的视觉树表示。
使用这个模型，alphaTab 可以非常高效地提供动态调整大小和重新布局。

alphaTab 使用的符号采用 [SMuFL](https://www.smufl.org/) 音乐字体 [Bravura](https://github.com/steinbergmedia/bravura)。

## 播放器
为了让音乐栩栩如生，alphaTab 内置了一个 MIDI 合成器。要播放乐谱，alphaTab 会将数据模型转换为 MIDI 命令，然后由基于 [TinySoundFont](https://github.com/schellingb/TinySoundFont) 的 MIDI 合成器播放。

我们获取数据模型，将其转换为 MIDI，将这个 MIDI 与 SoundFont2 一起放入音频引擎中，瞧，我们就能听到歌曲的演奏了。

alphaTab 可以提供用户交互和开箱即用的视觉光标。
