---
title: 设置项目
---

首先，我们将为新应用程序搭建舞台。
启动 Visual Studio 并创建一个 **WPF 应用程序 (.NET Core)** 类型的新项目。

<img src="/img/tutorial-net/create-project.png" />

然后输入项目名称并选择位置。

<img src="/img/tutorial-net/project-details.png" />

作为设置的最后一步，我们将安装 NuGet 包 `AlphaTab.Windows`，
其中包含我们使用所需的最重要控件。

在解决方案资源管理器中右键单击"引用"，然后选择"管理 NuGet 包..."
<img src="/img/tutorial-net/manage-nuget.png" />

然后搜索包 `AlphaTab.Windows` 并安装它。

<img src="/img/tutorial-net/install-alphatab.png" />

此外，安装 `FontAwesome.Sharp` 包，我们将在 UI 中使用它作为一些图标。
有了这些，我们就可以开始实际开发了。
