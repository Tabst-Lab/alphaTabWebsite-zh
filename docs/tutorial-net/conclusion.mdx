这就是关于如何学习在项目中使用 alphaTab 的教程。
您的下一步是前往 [参考文档](/docs/reference/settings)
了解 alphaTab 的完整功能集，以及您可能想要集成到应用程序中的其他功能。

<img src="/img/tutorial-net/result.png" height="400" />

根据您的经验和创造力，围绕我们共同构建的这个基础开发更多功能取决于您。
也许您想构建一个速度训练器或添加指板/钢琴显示。无论您尝试构建什么，
通常都归结为相同的几个步骤：

1. 查看参考文档，了解存在哪些事件、设置和 API 调用来完成您的任务。
2. 添加一些控件并设置它们的样式
3. 使用 API 对象及其提供的事件/方法将 UI 与 alphaTab 连接起来。

在真实的 WPF 应用程序中，您可能会将 alphaTab API 对象交给 ViewModel，并使用属性和命令绑定将 UI 与 ViewModel 连接起来。

欢迎通过我们的 GitHub 仓库向我们提供反馈。如果您需要帮助、发现错误或需要新功能，
只需在我们的 [主仓库](https://github.com/CoderLine/alphaTab/issues) 上使用相应的模板打开一个 Issue。
如果您有反馈、需要澄清或扩展文档页面，您可能更适合在
[本文档的仓库](https://github.com/CoderLine/alphaTabWebsite) 上打开一个新 issue。
