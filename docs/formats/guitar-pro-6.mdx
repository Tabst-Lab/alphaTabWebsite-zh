## 简介

> Guitar Pro 是一款适用于 Windows 和 Mac OS 的软件程序，允许所有音乐家阅读、编写和分享他们的指法谱。作为全球指法谱编辑领域的领导者，Guitar Pro 自 1997 年以来在全球已被下载超过 1500 万次。
> https://www.guitar-pro.com/

在第 6 版中，Guitar Pro 改为基于 XML 的文件格式。GPX 文件本身是一种类似 Zip 的自定义专有容器格式，包含多个文件：

* `score.gpif` - 代表音乐记谱法的主 XML 结构。
* `misc.xml` - 一个辅助 XML 文件，保存一些显示信息。
* `BinaryStylesheet` - 一个二进制文件，保存有关音乐记谱显示的各种设置的键值对（Guitar Pro 中的文件 > 样式表）。
* `PartConfiguration` - 一个二进制文件，保存有关在单轨和多轨视图中显示哪些音轨和谱表的信息。
* `LayoutConfiguration` - 一个二进制文件，保存有关用于显示乐谱的布局的信息（例如缩放级别）。

幸运的是，当 Guitar Pro 6 发布时，该格式的作者向社区解释了编码的工作原理。
 
**兼容性级别：** 成熟且经过充分测试
