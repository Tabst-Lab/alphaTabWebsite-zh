## 简介

Capella 是由德国公司 capella-software AG 开发的音乐记谱软件。
https://www.capella.de

旧版本的 Capella 使用二进制格式。alphaTab 仅兼容基于 XML 的格式。
Capella 文件是 Zip 归档，包含一个遵循 [CapXML 模式](https://www.capella.de/CapXML/) 的 `score.xml` 文件。

**兼容性级别：** 仅非常基本的支持，未经充分测试

Capella 通过"图形对象"而非语义方式来描述许多记谱元素。
这要求 alphaTab 对哪些确切的拍子/音符应该应用哪些元素进行最佳猜测。
