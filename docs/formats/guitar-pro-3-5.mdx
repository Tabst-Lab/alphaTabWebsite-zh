## 简介

> Guitar Pro 是一款适用于 Windows 和 Mac OS 的软件程序，允许所有音乐家阅读、编写和分享他们的指法谱。作为全球指法谱编辑领域的领导者，Guitar Pro 自 1997 年以来在全球已被下载超过 1500 万次。
> https://www.guitar-pro.com/

直到第 5 版，Guitar Pro 一直使用以二进制结构编码的专有文件格式。Arobas Music 曾经发布过第 4 版的文档。
以此为基础，任何进一步的格式细节都通过测试文件进行了手动逆向工程。

**兼容性级别：** 成熟且经过充分测试
