---
title: 项目设置
---

首先，我们将为新应用搭建基础环境。
启动 Android Studio，创建一个面向手机和平板的新项目，选择 Empty Views Activity。

:::info

重要提示：请务必选择名称中包含 "Views" 的项目模板，以便使用传统的 XML View 作为 UI 框架。
我们已将 [支持 Jetpack Compose](https://github.com/CoderLine/alphaTab/issues/1475) 列入路线图，作为更现代的新替代方案，但这还需要进一步开发。
如果你需要此功能，请为该 Issue 投票。如果你有 Android 开发经验，也可以尝试 [包装基于标准 View 的控件](https://developer.android.com/develop/ui/compose/libraries)。

:::

<img src="/img/tutorial-android/create-project.png" />

然后输入项目名称并选择保存位置。

<img src="/img/tutorial-android/project-details.png" />

项目创建并加载完成后，我们将 alphaTab 添加为项目依赖，并让 Android Studio 同步 Gradle 配置。

<img src="/img/tutorial-android/project-dependency.png" />

至此，我们就可以正式开始开发了。
