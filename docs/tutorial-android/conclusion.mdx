关于如何在项目中学习使用 alphaTab 的教程到此结束。
你的下一步应该是前往 [参考文档](/docs/reference/settings)
了解 alphaTab 的完整功能集，以及你可能想要集成到应用中的其他功能。

围绕我们共同构建的这个基础开发更多功能，取决于你的经验和创造力。
也许你想构建一个速度训练器，或者添加指板/钢琴显示。无论你尝试构建什么，
通常都可以归结为以下几个相同的步骤：

1. 查看参考文档，了解有哪些事件、设置和 API 调用可以满足你的任务需求。
2. 添加一些控件并设置样式
3. 使用 API 对象及其提供的事件/方法将 UI 与 alphaTab 连接起来。

欢迎在我们的 GitHub 仓库中向我们提供反馈。如果你需要帮助、发现了 bug 或需要新功能，
只需在我们的 [主仓库](https://github.com/CoderLine/alphaTab/issues) 上使用相应的模板提交 Issue。
如果你有反馈、需要澄清或扩展文档页面，你最好在此
[文档仓库](https://github.com/CoderLine/alphaTabWebsite) 上提交新 Issue。
