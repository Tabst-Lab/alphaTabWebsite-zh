# 前置条件

作为前置条件，你至少应该熟悉 Android 开发的基础知识。
alphaTab 是一个用于构建想要显示乐谱的应用/网站的**库**（或者如果你愿意，也可以叫 **SDK**），因此需要具备软件开发的基本知识。

为了简单起见，我们将省略遵循特殊模式等方面的内容，而是将功能代码放在靠近 UI 的地方。在真实的应用中，你可能会遵循更严格的组件分离，并使用响应式和分层架构。

本教程的目标是向你展示 alphaTab 的使用和交互方式，而不是教授正确的 Android 应用开发。

要学习本教程，你需要安装一个 Android IDE。我们将使用 Android Studio，
但除了项目设置之外，大部分操作都将在代码层面进行，所以你也可以使用任何你熟悉的 IDE。

那么，让我们开始吧！:wink:
