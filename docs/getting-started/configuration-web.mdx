---
title: 配置 (Web)
---

现在 alphaTab 已经[成为您项目的一部分](/docs/getting-started/installation-web)，是时候进行自定义配置了。
alphaTab 拥有相当多的设置项、事件和 API 方法可供交互。

## 设置

在安装指南中，您已经看到 alphaTab 会初始化到一个给定的 div 元素上。

只需创建一个 div 容器，放在您希望 alphaTab 位于页面上的位置。当使用页面布局时，alphaTab 会动态调整大小以适应 div 的可用宽度。如果您更喜欢固定布局，只需通过 CSS 在 div 上设置固定宽度，alphaTab 也不会再调整大小。

主命名空间 `alphaTab` 及其子命名空间（如 `model` 或 `midi`）包含 alphaTab 的所有类型和功能。主要的 API 是 `alphaTab.AlphaTabApi` 类，可用于初始化和与 alphaTab 交互：

```html
<div id="alphaTab"></div>
```
```js
const element = document.getElementById('alphaTab');
const api = new alphaTab.AlphaTabApi(element);
```

## 设置项

设置对象作为第二个参数传递给 API 对象的构造函数：

```js
const api = new alphaTab.AlphaTabApi(element, {
    // 任何设置项放在这里    
});

```

## 事件

alphaTab 的事件应该在 API 对象上订阅。
请参阅 [API 参考](/docs/reference/api) 以查找可用事件的完整列表。

每个事件都有 `.on(handler)` 和 `.off(handler)` 函数用于订阅或取消订阅。

```js
const api = new alphaTab.AlphaTabApi(element);
api.scoreLoaded.on( (score) => {
    console.log('乐谱已加载！', score);
});
```

## API

与 alphaTab 的主要交互通过 API 对象进行。
只需使用任何[可用的 API](/docs/reference/api) 来获取/设置详细信息或触发操作。

```js
const api = new alphaTab.AlphaTabApi(element);
api.tex('\title "Hello AlphaTab" . 1.1*4')
```
