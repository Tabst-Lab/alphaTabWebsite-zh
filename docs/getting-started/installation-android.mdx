## 获取您的副本

### Maven Central

我们通过 Maven Central 和 Sonatype OSSRH 提供基于最新开发版本的 Maven 包。

* 预发布快照：https://central.sonatype.com/repository/maven-snapshots/
* 发布版本：https://central.sonatype.com/artifact/net.alphatab/alphaTab

## 初始化 alphaTab

将 alphaTab 作为依赖项添加到您的项目后，您可以将 alphaTab 控件 `alphaTab.AlphaTabView` 添加到任何布局中。

:::info

重要提示：我们目前只提供经典的基于"视图"的控件。如果您对 Jetpack Compose 控件感兴趣，请在我们的路线图中为[此问题](https://github.com/CoderLine/alphaTab/issues/1475)投票，或尝试[包装经典控件](https://developer.android.com/develop/ui/compose/libraries)。

:::

```xml
<?xml version="1.0" encoding="utf-8"?>
<androidx.constraintlayout.widget.ConstraintLayout
    xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:tools="http://schemas.android.com/tools"
    xmlns:app="http://schemas.android.com/apk/res-auto"
    android:id="@+id/main_view"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    tools:context="net.alphatab.android.MainActivity"
    android:orientation="vertical">

    <alphaTab.AlphaTabView
        android:id="@+id/alphatab_view"
        android:layout_width="match_parent"
        android:layout_height="match_parent"
        app:layout_constraintBottom_toBottomOf="parent"
        app:layout_constraintTop_toBottomOf="parent"/>

</androidx.constraintlayout.widget.ConstraintLayout>
```

在您的 Activity 代码中，您可以通过获取该控件的引用来与 alphaTab 交互：

```kotlin
class MainActivity : ComponentActivity() {
    private lateinit var _alphaTabView: AlphaTabView

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)

        setContentView(R.layout.activity_main)
        _alphaTabView = findViewById(R.id.alphatab_view)

        val api = _alphaTabView.api;
        // 使用 alphaTab
    }
}

```

## 依赖项

对于 Kotlin for Android 版本，alphaTab 需要依赖一些第三方库来执行某些操作。

1. 对于渲染，可以使用内置的 Android Canvas，或者 alphaTab 依赖于 AlphaSkia 来进行现代跨平台图像渲染。Skia 是 Chrome 中使用的图形引擎，已被证明快速且可靠。我们建议使用 Skia 作为渲染引擎，而不是 Android Canvas。

2. 对于异步操作，使用 `org.jetbrains.kotlinx:kotlinx-coroutines-core`。

如果您希望获得对其他 UI 框架或音频库的支持，请随时联系我们。
