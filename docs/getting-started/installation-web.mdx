alphaTab 的网页版本适用于构建以各种方式显示和播放乐谱的网站。
您可以创建提供吉他谱下载的网站、为学生提供课程，或者只是想与他人分享您创作的音乐。您可以用 alphaTab 做什么，完全取决于您。

您可以通过 NPM 安装 alphaTab，也可以手动下载包并将其放入您的项目中。目前我们不提供 CDN。

        const element = document.getElementById('alphaTab');

## 附加说明

### 依赖项

AlphaTab 不需要任何其他库作为依赖项。它自带了所需的一切。
但是要在网页中运行 alphaTab 并使用所有功能，仍然涉及 2 个依赖项：

- [Bravura](https://github.com/steinbergmedia/bravura) 是我们选择的音乐字体。它是一种免费字体，包含[音乐符号](https://www.smufl.org/)。
AlphaTab 捆绑了这种字体，并将其放在脚本文件旁边。
- 要播放音频，需要一个 [SoundFont2](https://en.wikipedia.org/wiki/SoundFont) 文件。它包含要通过 alphaTab 的 MIDI 合成器播放的乐器音频采样。
AlphaTab 附带了一份基于 SONiVOX 的 SoundFont 副本，它是 Android 开源项目的一部分，可在 [Apache 许可证](https://www.apache.org/licenses/LICENSE-2.0)下免费使用。
