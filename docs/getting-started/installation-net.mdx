---
title: 安装 (.net)
---

alphaTab 的 .net 版本可用于在服务器、命令行工具或 Windows 桌面应用程序上渲染乐谱。AlphaTab 提供适用于 .net standard 2.0 或 .net 8.0 的 .net 版本。

## 获取您的副本

### NuGet.org

我们通过 NuGet.org 提供基于最新开发版本的 NuGet 包。
像往常一样安装包：

**核心包 (.net standard 2.0)**

> https://www.nuget.org/packages/AlphaTab/

**Windows 包 (.net core 8.0 - WPF/WinForms)**

> https://www.nuget.org/packages/AlphaTab.Windows/

### 本地副本

虽然不推荐，但您可以通过下载 Nupkg 并将其解压到本地文件夹来获取最新的 DLL。
之后，您可以从该文件夹引用这些 DLL。

## 初始化 alphaTab

### 控制台

对于控制台应用程序，您将开始使用 alphaTab 的底层 API，如 `ScoreLoader` 和 `ScoreRenderer`。
通常，alphaTab 基于 `AlphaTabApi` 为 UI 平台提供控件。但对于没有 UI 的平台，
只需开始使用 alphaTab 提供的普通类即可。您可以参考 GitHub 仓库中的示例代码来快速入门。

```cs
// 加载乐谱
var score = AlphaTab.Importer.ScoreLoader.LoadScoreFromBytes(File.ReadAllBytes(args[0]));

// 使用 svg 引擎和所需的渲染宽度渲染乐谱
var settings = new AlphaTab.Settings();
settings.Core.Engine = "skia";
var renderer = new AlphaTab.Rendering.ScoreRenderer(settings)
{
    Width = 970
};
var partialImages = new List<SKImage>();
var totalWidth = 0;
var totalHeight = 0;
renderer.PartialRenderFinished.On(r => { images.Add((SKImage) r.RenderResult); });
renderer.RenderFinished.On(r =>
{
    totalWidth = (int) r.TotalWidth;
    totalHeight = (int) r.TotalHeight;
});
renderer.RenderScore(score, new double[] { track.Index });
```

### WPF

对于 WPF，我们提供了一个具备 alphaTab 核心功能的 UI 控件：

```xml
<Window x:Class="AlphaTab.Samples.Wpf.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        xmlns:wpf="clr-namespace:AlphaTab.Wpf;assembly:AlphaTab.Windows"
        Title="AlphaTab" Height="800" Width="600" WindowState="Maximized">
    <wpf:AlphaTab Tracks="{Binding TracksToDisplay}">
    </wpf:AlphaTab>
</Window>
```

```cs
public IEnumerable<AlphaTab.Model.Track> TracksToDisplay { get; }
```

### WinForms

还有一个 WinForms 控件可供您使用：

```cs
var control = new AlphaTab.WinForms.AlphaTabControl();
control.Dock = System.Windows.Forms.DockStyle.Fill;
this.Controls.Add(control);
control.Tracks = new []{ score.Tracks[0] };
```

## 依赖项

对于 .net 版本，alphaTab 需要依赖一些第三方库来执行某些操作。

1. 对于渲染，可以使用内置的图形库 GDI+，或者 alphaTab 依赖于 AlphaSkia 来进行现代跨平台图像渲染。Skia 是 Chrome 中使用的图形引擎，已被证明快速且可靠。我们建议使用 Skia 作为渲染引擎，而不是 GDI+。

2. 对于音频播放，alphaTab 依赖于 NAudio，用于播放合成的声音。

如果您希望获得对其他 UI 框架或音频库的支持，请随时联系我们。
