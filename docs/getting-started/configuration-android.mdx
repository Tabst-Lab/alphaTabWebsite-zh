---
title: 配置 (Android)
---

现在 alphaTab 已经[成为您项目的一部分](/docs/getting-started/installation-android)，是时候进行自定义配置了。
alphaTab 拥有相当多的设置项、事件和 API 方法可供交互。

## 设置

在安装指南中，您已经看到 alphaTab 的设置取决于您使用的 UI 框架。

### 后台工作线程或自定义控件

对于非 UI 用途，没有太多要说的：使用可用的类即可。这种用法可能比依赖预构建的 UI 组件稍微复杂一些，需要阅读一些文档。如果您在运行某些功能时需要帮助，请随时联系我们。
除此之外，最简单的方式可能是[查看 alphaTab 是如何被使用的](https://github.com/CoderLine/alphaTab/tree/develop/src.kontrol)来构建所提供的控件。

### Android 控件

对于普通的 Android UI，我们提供了一个开箱即用、具备主要功能的控件。只需将该控件嵌入到您的布局 XML 中并获取其引用即可。

```xml
<?xml version="1.0" encoding="utf-8"?>
<androidx.constraintlayout.widget.ConstraintLayout
    xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:tools="http://schemas.android.com/tools"
    xmlns:app="http://schemas.android.com/apk/res-auto"
    android:id="@+id/main_view"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    tools:context="net.alphatab.android.MainActivity"
    android:orientation="vertical">

    <alphaTab.AlphaTabView
        android:id="@+id/alphatab_view"
        android:layout_width="match_parent"
        android:layout_height="match_parent"
        app:layout_constraintBottom_toBottomOf="parent"
        app:layout_constraintTop_toBottomOf="parent"/>

</androidx.constraintlayout.widget.ConstraintLayout>
```

在您的 Activity 代码中，您可以通过获取该控件的引用来与 alphaTab 交互：

```kotlin
class MainActivity : ComponentActivity() {
    private lateinit var _alphaTabView: AlphaTabView

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)

        setContentView(R.layout.activity_main)
        _alphaTabView = findViewById(R.id.alphatab_view)

        val api = _alphaTabView.api;
        // 使用 alphaTab
    }
}

```

## 设置项

设置项对于按您的偏好配置 alphaTab 的显示非常重要。

UI 控件暴露了一个 `settings` 属性，可用于更改任何所需的配置。
设置对象本身的更改不会自动被检测到。需要调用 `_alphaTabView.api.updateSettings()` 来触发 alphaTab 的更新。

此外，还有一个 `tracks` 属性，可以填充该属性来更改 alphaTab 渲染的音轨。


## API

主要的 alphaTab API 只能通过 UI 控件上的 `api` 属性访问。它提供了一组方便的方法、属性和事件来控制 alphaTab。

```csharp
_alphaTabView.api.tex("\\title \"Hello AlphaTab\" . 3.3*4");
```

## 事件

事件注册在 alphaTab 类上进行。您可以通过 `Api` 属性访问主要的 `AlphaTabApi` 对象。
从那里，您可以使用 alphaTab 暴露的任何 API 和方法。

事件通过 `eventName.on(handler)` 和 `eventName.off(handler)` 进行订阅和取消订阅。

```kotlin
_alphaTabView.api.playedBeatChanged.on { beat -> {
    updateFretboard(beat)
}
```
