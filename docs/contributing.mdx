我们很高兴听到您想要为 alphaTab 做出贡献。有多种方式可以为 alphaTab 做出贡献。
您可以报告错误、请求功能，或者实际开始为 alphaTab 源代码做出贡献。

## 参与其中

如果您正在项目中使用 alphaTab，您可能会遇到彩蛋（也就是 bug），或者需要 alphaTab 中尚不存在的新功能。

对于错误，请在我们的仓库 [GitHub](https://github.com/CoderLine/alphaTab/issues/new/choose) 上创建 issue。
如果您想请求功能、改进或需要一般帮助，可以使用 [GitHub Discussions](https://github.com/CoderLine/alphaTab/discussions) 作为论坛与社区联系。

:::important
请遵循模板，不要删除所有信息并只写一行问题。获取模板中要求的所有信息对于判断请求的重要性和内容非常重要。您花 2 分钟的努力，可以大大减少我们这边的工作量。我们将关闭任何不遵循模板的 issue。
:::


## 加入代码开发

您是开发者？您想为 alphaTab 贡献代码？太棒了！alphaTab 在 GitHub 上使用类似 GitFlow 的分支策略进行开发。

主要的新开发发生在 `develop` 分支上，新功能通常在 `feature/{功能或 issue 名称}` 分支上开发。要开始使用，您可以将 alphaTab 分叉到您的账户中，并以您喜欢的方式开始准备修复/功能。然后只需发起一个拉取请求。
如果您熟悉 Git 和 GitHub，您就知道该怎么做 ;)

### 许可证

alphaTab 在 MPL-2.0 下开发，您贡献的任何源代码都同意将您更改的所有权转让给 alphaTab。
我们这样做并不是想"夺走"您的更改，而是希望保持将来可能将许可证更改为更开放或不同的许可证（例如 MIT）的自由，而无需与数百人确认此更改是否可行。当然，我们也不会在没有公开讨论的情况下做出这样的更改。

一个主要目标是让 alphaTab 成为一个免费且开源的库，供任何人集成。

### 工具链

您还在这里？这听起来很有希望。您已经分叉了，克隆了仓库，现在您准备好开始开发了。
但如何开发是个大问题。在我们实际接触代码之前，了解 alphaTab 的工具链是很有帮助的。

AlphaTab 在开发语言上有着悠久的历史。经过这么多年，alphaTab 最终使用 TypeScript 作为主要开发语言。这一变更发生在 2020 年 4 月。在此之前，AlphaTab 是用 C# 开发的，使用了一个特殊的工具链，通过 Haxe 生成 JavaScript 代码。

alphaTab 的 .net 和 Kotlin for Android 版本仍然通过基于 TypeScript 编译器的特殊编译器提供。它将 TypeScript 源代码翻译成 C#，然后从那里进一步编译。

<img src="/img/toolchain.svg" />

这就引出了 alphaTab 开发的下一个方面。它的目标是零依赖和跨平台/语言使用。
alphaTab 的主要模块编写为独立的源代码，没有第三方依赖，并且采用可以在任何具有垃圾回收器的潜在平台上执行的样式（.net、JavaScript、Kotlin for Android 等）。提供平台原生解决方案给市场上的任何主要平台是一项积极的策略。

### 开发环境

主要开发可以使用任何以 Web 为中心的 IDE 或编辑器进行。由您决定使用哪一个。
我们推荐 Visual Studio Code。

除了 IDE 之外，您还需要以下工具：

* [Node.js](https://nodejs.org/)
* [.net SDK](https://dotnet.microsoft.com/download)
* [Java 和 Android SDK](https://developer.android.com/studio)

之后，您可以运行以下命令在输出文件夹中获取编译版本的 alphaTab：

```
> npm install
> npm start
```

### NPM 脚本

仓库有一组 NPM 脚本，负责编译和测试等操作。通过 `npm run <脚本名称>` 执行它们。有关更多详细信息，请参阅 [npm 文档](https://docs.npmjs.com/cli/run-script)。

* `clean` - 清理所有输出
* `lint` - 检查源代码的样式违规
* `generate-typescript` - 生成一些 TypeScript 源文件（例如版本信息和序列化器）。

#### Web

* `build` - 使用当前代码状态编译 alphaTab 的 Web 版本
* `dev` - 在开发期间使用，通过监视器和增量编译快速构建 alphaTab
* `test` - 在 Chrome 中运行单元测试套件

#### C#/.net

* `generate-csharp` - 将 TypeScript 代码库翻译成 C#
* `build-csharp` - 使用当前代码状态编译 C#/.net 版本的 alphaTab
* `test-csharp` - 运行 C# 的单元测试套件

#### Kotlin for Android

* `generate-kotlin` - 将 TypeScript 代码库翻译成 Kotlin
* `build-kotlin` - 使用当前代码状态编译 Kotlin 版本的 alphaTab
* `test-kotlin` - 运行 Kotlin 的单元测试套件
