alphaTab 支持多种不同的布局方式，以各种方式对齐小节。

## 页面布局
所有小节并排对齐成行，直到该行排满。
<AlphaTab file="/files/features/Skillet.gp5" settings={ {
	display: { 
		layoutMode: 'page' 
	}
} } />

## 多音轨
您想同时渲染多个音轨？没问题
<AlphaTab file="/files/features/Skillet.gp5" tracks={[0,3]} settings={ {
	display: { 
		layoutMode: 'page' 
	}
} } />

## 页面布局（自定义宽度）
所有小节并排对齐成行，直到该行排满。

<div style={ {width: '600px'} }>
<AlphaTab file="/files/features/Skillet.gp5" settings={ { 
	display: { 
		layoutMode: 'page' 
	}
} } />
</div>

## 页面布局（每行 5 小节）
您可以配置每行应放置多少小节
<AlphaTab file="/files/features/Skillet.gp5" settings={ {
	display: { 
		barsPerRow: 5 
	}
} } />

## 页面布局（第 5 到第 8 小节）
也可以只渲染音轨中的部分小节。
<AlphaTab file="/files/features/Skillet.gp5" settings={ {
	display: { 
		startBar: 5, 
		barCount: 4 
	}
} } />

## 水平布局
这是另一种可用的布局类型。所有小节水平对齐。
<div style={ { width: '600px', overflow: 'auto' } }>
<AlphaTab file="/files/features/Skillet.gp5" settings={ {
	display: { 
		layoutMode: 'horizontal' 
	}
} } />
</div>

## 水平布局（第 5 到第 8 小节）
您也可以使用此布局过滤渲染的小节。
<AlphaTab file="/files/features/Skillet.gp5" settings={ {
	display: { 
		layoutMode: 'horizontal',
		startBar: 5,
		barCount: 4
	}
} } />


## 多小节休止

alphaTab 可以从输入文件中加载是否应使用多小节休止的信息，然后在显示时相应地合并小节。
如果小节为空或仅包含休止符，则会自动合并。

对于 Guitar Pro 文件，格式从文件中加载；对于 alphaTex，可以通过一系列元数据选项进行指定。
样式表上可用的选项有：


<AlphaTab tex="true" tracks="all">{`
\\multiBarRest
.
\\track "Piano 1" "pno1"
    \\staff {score}
    C4 D4 E4 F4 | r | r | C4 D4 E4 F4 | r | r | r | C4

\\track "Piano 2" "pno1"
    \\staff {score}
    C4 D4 E4 F4 | r | r | C4 D4 E4 F4 | r | r | r | r |
`}</AlphaTab>
