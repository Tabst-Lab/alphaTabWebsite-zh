## 节奏
如果您只显示吉他指法谱，添加节奏谱表来显示时值可能会很有用。您可以在指法谱的上方或下方执行此操作。
<AlphaTab file="/files/features/Rhythm.gp5" settings={ {
	staveProfile: 'tab', 
	notation: { rhythmMode: 'showwithbars'}
} } />

## 带符杠的节奏
如果您更喜欢用符杠而不是符杠来表示单个音符，也可以实现。
<AlphaTab file="/files/features/Rhythm.gp5" settings={ {
	staveProfile: 'tab', 
	notation: { rhythmMode: 'showwithbeams'}
} } />

## 弦数变化
alphaTab 将为弦乐器渲染指法谱。它会处理弦数并按您期望的方式显示指法谱。
