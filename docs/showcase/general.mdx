## 括号和连谱号
alphaTab 会在属于同一组的谱表之间渲染括号和连谱号。alphaTab 支持与 Guitar Pro 相同的 3 种模式：

* 无括号 - 完全不绘制括号。
* 分组谱表 - 同一音轨的谱表将分组在一起。如果有多个"标准记谱法"谱表，则绘制连谱号，否则绘制括号。
* 分组相同乐器 - 同一乐器的多个音轨将分组在一起。如果乐器的谱表需要连谱号，则不分组。

该模式从 Guitar Pro 文件中加载，可以通过 [alphaTex 配置](/docs/alphatex/score-metadata.mdx#bracketextendmode) 或在数据模型上通过 `score.stylesheet.bracketExtendMode` 进行配置。

<AlphaTab tex="true" tracks="all">{`
\\bracketextendmode GroupSimilarInstruments
.
\\track "Piano1"
    \\staff {score}
	\\instrument piano
    C4 D4 E4 F4
    \\staff {score}
    \\clef f4 C3 D3 E3 F3
\\track "Piano2"
    \\staff {score}
	\\instrument piano
    C4 D4 E4 F4
\\track "Flute 1"
    \\staff { score }
	\\instrument flute
    C4 D4 E4 F4
\\track "Flute 2"
    \\staff { score }
	\\instrument flute
    \\clef f4 C3 D3 E3 F3
\\track "Guitar 1"
    \\staff { score tabs }
    0.3.4 2.3.4 5.3.4 7.3.4 
`}</AlphaTab>


## 音轨名称
alphaTab 以配置的格式在选定的谱表系统中渲染音轨名称。

对于 Guitar Pro 文件，格式从文件中加载；对于 alphaTex，可以通过一系列元数据选项进行指定。
样式表上可用的选项有：

* `score.stylesheet.singleTrackTrackNamePolicy` - 配置仅渲染单个音轨时如何显示音轨名称。（隐藏、仅第一个系统、所有系统）
* `score.stylesheet.multiTrackTrackName` - 配置渲染多个音轨时如何显示音轨名称。
* `score.stylesheet.firstSystemTrackNameMode` - 配置在第一个系统上显示什么名称（完整或简短音轨名称）。
* `score.stylesheet.otherSystemsTrackNameMode` - 配置在其他系统上显示什么名称。
* `score.stylesheet.firstSystemTrackNameOrientation` - 第一个系统上音轨名称的方向（水平或垂直）
* `score.stylesheet.otherSystemsTrackNameOrientation` - 其他系统上音轨名称的方向（水平或垂直）

<AlphaTab tex="true" tracks="all">{`
\\singletracktracknamepolicy AllSystems
\\firstsystemtracknamemode fullname
\\othersystemstracknamemode shortname
\\firstsystemtracknameorientation horizontal
\\othersystemstracknameorientation vertical
.
\\track "Piano 1" "pno1" { defaultsystemslayout 3 }
    \\staff {score}
    C4 D4 E4 F4 | C4 D4 E4 F4 | C4 D4 E4 F4 | C4 D4 E4 F4 | C4 D4 E4 F4 |
`}</AlphaTab>
