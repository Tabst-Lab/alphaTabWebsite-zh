一个 alphaTex 文件就是一个小节的列表，每个小节都有元数据和内容。出于组织原因，我们建议
将描述一般歌曲信息的元数据标签添加到文件开头，并将外部媒体同步点
添加到文件末尾：

```title=General File Structure
/* Song Metadata */
/* Song Contents */
/* Sync Points */
```

:::note
在 alphaTex 1.7 之前，这 3 个部分需要用 `.` 分隔。这在 1.7 中得到了改进，现在应该省略分隔点。

```title=Pre 1.7 General File Structure
/* Song Metadata */
.
/* Song Contents */
.
/* Sync Points */
```
:::

## 小节

小节（即 measures）以一个可选的元数据标签列表开头，后跟小节中包含的
节拍。有关可在此处应用的标签的详细信息，请参阅[小节元数据](./bar-metadata.mdx)。

一个小节以竖线 `|` 符号结束。

<AlphaTexSample>{`
// bar 1 metadata tags
\\clef G2 \\ks 
    // bar 1 contents
    Cb C4 
|  
// bar 2 metadata tags
\\ks A
    // bar 2 contents
    C4 
`}</AlphaTexSample>

## 节拍

节拍将同时演奏的多个音符分组。节拍的一般组成部分是

* `duration-change content duration effects multiplier`


<AlphaTexSample tracks={"all"}>{`
:4
    C4
    (C4 D4).8
    (C4 D4) { f }
    C4.16 * 2
    C4.4 
`}</AlphaTexSample>

### 时值变化（可选）

时值变化允许轻松更改所有后续节拍的时值。语法是：

`:Duration`，其中 `Duration` 是一个描述新时值的数字：
* `:-4` 四倍全音符
* `:-2` 二倍音符
* `:1` 全音符
* `:2` 二分音符
* `:4` 四分音符
* `:8` 八分音符
* `:16` 十六分音符
* `:32` 三十二分音符
* `:64` 六十四分音符
* `:128` 一百二十八分音符
* `:256` 二百五十六分音符

你也可以在时值之后指定一些属性来定义连音。

`:4 {tu 3 2}`

有关更多详细信息，请参阅[连音效果](./beat-properties.mdx#tu)。

<AlphaTexSample>{`
:16 // 16th notes from here
    3.3
    4.3 
    5.3
    6.3
:4 { tu 3 } // quarter notes triplets
    3.3
    4.3
    5.3
:8 
    3.3 * 3
`}</AlphaTexSample>

### 节拍内容（必需）

最关键的部分是描述节拍的内容，它可以是以下选项之一：

* 休止符
* 多个同时演奏的音符（用括号分组）
* 单个演奏的音符

休止符只需指定一个 `r` 即可表示：

<AlphaTexSample>{`
:4 r r r r
`}</AlphaTexSample>

多个[音符](#notes)可以用括号 `()` 分组。与值列表类似，你也可以只指定
一个音符并省略括号。

<AlphaTexSample>{`
:4 
    C4 // single note on beat
    (C4 E4) // multiple notes with parenthesis
`}</AlphaTexSample>

### 节拍时值（可选）

另一种指定节拍时值的方法是在节拍内容后附加 `. duration`。
历史上，新的时值也会被下一个节拍记住。作为节拍效果指定的连音不会被记住。
<AlphaTexSample>{`
C4 .4
C4 .8
C4 // .8 remembered
C4 .2
`}</AlphaTexSample>

### 节拍效果（可选）

节拍效果可以作为属性应用于节拍之后。请参阅[节拍属性](./beat-properties.mdx)以了解所有可用的效果。

<AlphaTexSample>{`
:4
    (C4 D4) { tp 8 } 
    C4 { f }
    r.2 {txt "Pause here"}
`}</AlphaTexSample>

### 节拍乘数（可选）

此功能允许通过“乘”来重复相同的节拍多次。
只需在节拍后指定 `* times`，其中 `times` 是你想要的副本数。

<AlphaTexSample>{`
:4
    // 4 times the same A-chord 
    (0.1 2.2 2.3 2.4 0.5) * 4 
`}</AlphaTexSample>

## 音符

根据演奏的乐器，你的小节中可以有 3 种音符之一。
不能混合使用，因此请确保所有音符一致地指定：

* 像吉他这样的有品和弦乐器，其音符表示为 `fret.string`
* 打击乐/鼓的音符表示为发音名称。
* 其他有音高的乐器的音符表示为音符名称。

在每个音符之后，可以可选地将音符效果指定为属性：`note-value {note-properties}`。

:::info
AlphaTab 尝试根据第一个音符检测你正在编写哪种类型的谱表。
:::

### 有品音符

如果当前谱表是弦乐器（相应地指定了 `\tuning` 或 `\instrument`），
音符表示为按下的品和弦。最终音符高度会被计算出来。

<AlphaTexSample>{`
:1
    (12.1 {sib} 14.2 {sib b (0 4)})
    12.1 { v }
`}</AlphaTexSample>

### 打击乐 / 鼓音符

在打击乐器上，你指定应该作为音符演奏的发音。
打击乐可以是带引号的字符串或标识符（不带引号的名称）。

更多详细信息请参阅 [`\articulation`](./staff-metadata.mdx#articulation) 元数据文档。

<AlphaTexSample>{`
\\instrument percussion
\\articulation defaults
:4
    (KickHit RideBell) 
    r 
    KickHit 
    KickHit
`}</AlphaTexSample>

### 有音高音符

有音高音符以组合名称表示，包含：

* 音名 (`C`,`D`,`E`,`F`,`G`,`A`,`B`,`C`)
* 变音记号 (`#`, `b`, `bb`, `x`, `##`,..; 有关变音记号处理的详细信息，请参阅[变音记号](./note-properties.mdx#acc))
* 八度（一个数字）

<AlphaTexSample>{`
C4
C#4
Ebb4
Dx5 
`}</AlphaTexSample>

### 音符效果

有关音符所有支持的效果列表，请参阅[音符属性](./note-properties.mdx)。


<AlphaTexSample>{`
:2
    3.3 { b (0 4) } // note bend
    (
        3.3 { v } // Vibrato
        3.2 { sib } // slide into from below
    )
`}</AlphaTexSample>

如果节拍中只有 1 个音符，你可以在同一个属性列表中指定音符和节拍效果。

<AlphaTexSample>{`
:2
    // combined effects
    3.3 {
        b (0 4)     // note effect
        txt "Bend"  // beat effect
    }
    // separated effects 
    3.3 
        { b (0 4) }     // note effect
        { txt "Bend" }  // beat effect
`}</AlphaTexSample>

## 音轨、谱表和声部

一首歌曲可能由多个音轨和谱表组成，它们保存着歌曲数据。有一些特殊的元数据标签标记着
这些新结构的开始。有关更多详细信息，请参阅[结构元数据](./structural-metadata.mdx)。

<AlphaTexSample tracks={"all"}>{`
\\track "Track 1"
    \\staff {score} // first staff
        \\voice // first voice 
            C4 D4 E4 F4 | C4 D4 E4 F4
        \\voice // second voice
            C5 D5 E5 F5 | C5 D5 E5 F5
    \\staff {tabs} // second staff
        3.5 5.5 7.5 8.5 | 3.5 5.5 7.5 8.5
\\track "Track 2"
     1.2 3.2 5.2 6.2
`}</AlphaTexSample>

你只需要指定这些结构标签来开始一个新元素。第一个初始元素是隐式开始的。

<AlphaTexSample tracks={"all"}>{`
// first track
    // first staff
        // first voice 
            C4 D4 E4 F4 | C4 D4 E4 F4
        \\voice // second voice
            C5 D5 E5 F5 | C5 D5 E5 F5
    \\staff {tabs} // second staff
        3.5 5.5 7.5 8.5 | 3.5 5.5 7.5 8.5
\\track "Track 2"
     1.2 3.2 5.2 6.2
`}</AlphaTexSample>
