在本节中，您可以找到有关如何使用 AlphaTex 编写乐谱的所有详细信息。
AlphaTex 是一种用于为 AlphaTab 编写乐谱的文本格式。可以通过设置
[`tex`](/docs/reference/settings/core/tex) 选项或通过 API 上的 [`tex()`](/docs/reference/api/tex) 方法来启用 AlphaTex 加载。
AlphaTab 将从元素内容中加载 tex 代码并解析它。您也可以像其他格式一样从文件中加载它。
AlphaTex 支持 alphaTab 支持的大部分功能。
如果您发现缺少任何想要的功能，欢迎随时在
[GitHub 上发起讨论](https://github.com/CoderLine/alphaTab/discussions/new)，以便我们共同找到一个好的解决方案。
