如果你将 alphaTex 与编程或脚本语言进行比较，你会在这个语言中发现类似的结构。alphaTex（顾名思义）借鉴了
LaTeX 的一些方面，LaTeX 是一种广为人知的文档编写语言。随着 alphaTex 的发展，它形成了各种独特的语法结构，在此进行描述。

将 alphaTex 保存到文件时，我们建议使用文件扩展名 `.atex`。

## 注释

支持 C 风格注释，通过 `// 单行注释` 和 `/* 多行注释 */`。你可以在 alphaTex 文件中的任何地方使用它们，
以进一步注释你编写的文档，用于结构或组织目的。

## 字符串

文本值以带引号的字符串形式表示，类似于大多数编程语言。支持单引号和双引号。

* `"双引号字符串"`
* `'单引号字符串'`

此外，还支持以下转义序列：

* `\n` 换行
* `\r` 回车
* `\t` 制表符
* `\uXXXX` Unicode 字符，其中 XXXX 是一个 4 位十六进制数字。
* `\\` 反斜杠
* `\'` 或 `\"` 引号字符

## 数字

alphaTex 支持整数和小数。小数只允许在某些特定位置使用，以避免与其他语法结构重叠。

示例：

* `10`
* `-10`
* `0.5`
* `-4.5`

## 参数 / 参数列表

在各个地方使用参数来描述值，如拍号或推弦点。
如果有多个值，参数应该用括号 `(values)` 包裹。如果只有一个值，可以省略括号。

单个值可以是：

* 整数：`3`, `-10`
* 小数：`3.3`, `-10.5`
* 字符串：`"Hello"`, `'Hello'`
* 特殊标识符：`true`, `hide`, `x`

基本示例

* `( 1 2 3 )`  一个数字列表
* `("Test" 3 hide)` 一个混合类型值列表

实际示例

* `\ts (3 4)` 一个 3/4 拍号（在小节级别指定）
* `12.2 { b (0 4 0) }` 一个音符推弦，描述一个全音符推弦和释放
* `\title ("Song Title" "Title: %TITLE%" left)` 一个歌曲标题，显示为 `Title: Song Title`，左对齐。

你可以将这个语法结构与在脚本或编程语言中调用函数进行比较：`myFunction(value1, value2)`。alphaTex 的区别在于，各个参数
通过简单的空格分隔，单个参数调用不需要括号。

## 属性

属性是描述元素额外可选方面的键值对列表。
它们用于为音符和节拍添加效果，指定应在谱表中显示哪些符号等等。

属性总是用大括号包裹。属性以一个标识符开头，描述该属性，可选地后跟其值作为值列表。

示例：
* `\track "Track Name" { color "#FF0000"}`
* `\staff {score}`
* `C4 {b (0 4) v txt "Bend with Vibrato"}`

属性标识符不区分大小写。

## 元数据标签

元数据标签是与 LaTeX 最相似的结构。元数据用于描述数据模型中的各种元素。

元数据标签的主要语法是：`\tag parameters {properties}`。
从语法角度来看，`parameters` 和 `{properties}` 都是可选的。根据 `tag` 的不同，可能需要指定值。

示例：

* `\title "Song Title"`
* `\track "Track Name" {color '#FF0000'}`
* `\ts (3 4)`

元数据标签标识符不区分大小写。

### 元数据标签参数

元数据标签可能有一个或多个值作为参数传入。支持的确切值（必需或可选）取决于标签。
有关更多详细信息，请参阅上面的[参数](#parameters--argument-lists)。

### 元数据标签属性

元数据标签可能有一个或多个属性。支持的确切值取决于标签。
有关更多详细信息，请参阅上面的[属性](#properties)。
