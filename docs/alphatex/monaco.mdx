title: Monaco 编辑器集成
since: 1.7.0
---

[Monaco](https://microsoft.github.io/monaco-editor/) 是为 Visual Studio Code 提供支持的代码编辑器，提供高级编码功能。
不幸的是，Monaco 没有内置对语言服务器的支持，但它提供了自己的 API。

你可以选择像 https://github.com/TypeFox/monaco-languageclient 这样的高级集成，或者依赖我们在 [`@coderline/alphatab-monaco`](https://www.npmjs.com/package/@coderline/alphatab-monaco) 中提供的更轻量级集成

这个包允许将 Monaco 与在 Web Worker 中运行的 alphaTab 语言服务器集成，提供其所有功能。

本指南重点介绍在浏览器环境中与 Monaco 的集成。我们还假设导入的依赖项通过某种机制（如打包工具）可用。

> [!WARNING]
> 此集成仍处于实验阶段。它在页面上只有一个编辑器时工作正常，但
> 尚未很好地集成到具有多个编辑器的更复杂环境中。

我们还在开发游乐场中使用这个模块。你可以通过克隆 alphaTab 并在 VS Code 中打开它来查看和测试（它会编译并启动游乐场）。
然后在菜单中打开 `alphaTex 编辑器`。

## TextMate 语法

alphaTab 提供了一个 TextMate 语法，但 Monaco 并不原生支持 TextMate 语法。
我们使用 Microsoft 的两个包来弥补这一差距：

* `vscode-textmate` 管理 TextMate 语法的加载
* `vscode-oniguruma` 是用于 TextMate 语法中 Oniguruma 正则表达式的引擎（通过 WebAssembly）。

```ts
//
// Monaco editor worker (see Monaco docs)

// @ts-expect-error
import editorWorker from 'monaco-editor/esm/vs/editor/editor.worker?worker';
self.MonacoEnvironment = {
    getWorker: () => {
        return new editorWorker();
    }
};

// 
// alphaTex Grammar Support

// load the WebAssembly file (e.g. via ajax or other mechanisms)
// it is shipped together with the vscode-oniguruma NPM package
const onigurumaWasm:ArrayBuffer = await load(new URL('vscode-oniguruma/release/onig.wasm', import.meta.url));

import { addTextMateGrammarSupport } from '@coderline/alphatab-monaco/textmate';

// Setup general textmate grammar support (also other grammars beside alphaTex could be used)
const textMateSupport = addTextMateGrammarSupport(onigurumaWasm);

// Register the alphaTex grammar
await registerAlphaTexGrammar(textMateSupport);

//
// Setup editor
import * as monaco from 'monaco-editor';
const element = document.querySelector<HTMLElement>('#editor');
const editor = monaco.editor.create(element!, {
    value: '\\title "Hello World"',
    language: 'alphatex',
    automaticLayout: true
});
```

此时你应该会得到一个带有语法高亮的编辑器。

## 启动语言服务器

为了将剩余功能引入 Monaco，我们首先必须在 Web Worker 中启动 alphaTex 语言服务器。

NPM 包提供了一个可以作为 Web Worker 生成的模块：

```ts
const lspWorker = new Worker(new URL('@coderline/alphatab-monaco/worker', import.meta.url));
```

或者，你也可以在项目中创建自己的 worker 文件并启动语言服务器：

```ts title="lsp.worker.ts"
// Variant 1
import '@coderline/alphatab-monaco/worker';
// Variant 2: 
import { startWebWorkerLanguageServer } from '@coderline/alphatab-language-server';

const workerGlobalThis = globalThis as unknown as DedicatedWorkerGlobalScope;
startWebWorkerLanguageServer(workerGlobalThis, workerGlobalThis);
```

```ts title="monaco.ts"
const lspWorker = new Worker(new URL('./lsp.worker.ts', import.meta.url));
```

## 设置 Monaco LSP 集成

与此 LSP worker 的集成非常简单。只需调用 `setupLspAlphaTexLanguageSupport`。

```ts
//
// Monaco editor worker (see Monaco docs)

// @ts-expect-error
import editorWorker from 'monaco-editor/esm/vs/editor/editor.worker?worker';
self.MonacoEnvironment = {
    getWorker: () => {
        return new editorWorker();
    }
};

// 
// alphaTex Grammar Support

// load the WebAssembly file (e.g. via ajax or other mechanisms)
// it is shipped together with the vscode-oniguruma NPM package
const onigurumaWasm:ArrayBuffer = await load(new URL('vscode-oniguruma/release/onig.wasm', import.meta.url));

import { addTextMateGrammarSupport } from '@coderline/alphatab-monaco/textmate';

// Setup general textmate grammar support (also other grammars beside alphaTex could be used)
const textMateSupport = addTextMateGrammarSupport(onigurumaWasm);

// Register the alphaTex grammar
await registerAlphaTexGrammar(textMateSupport);

//
// Setup editor
import * as monaco from 'monaco-editor';
const element = document.querySelector<HTMLElement>('#editor');
const editor = monaco.editor.create(element!, {
    value: '\\title "Hello World"',
    language: 'alphatex',
    automaticLayout: true
});

//
// Setup the LSP support
import { addTextMateGrammarSupport } from '@coderline/alphatab-monaco/textmate';
await setupLspAlphaTexLanguageSupport(editor);
```

> [!WARNING]
> 我们在[开发游乐场](https://github.com/CoderLine/alphaTab/blob/develop/packages/playground/alphatex-editor.ts)中生成 worker 时注意到了一些奇怪的 Vite 行为。
> 奇怪的是，Vite 实际上并没有打包 worker 中包含的依赖项，导致语言服务器无法启动的问题。
> 我们不得不创建一个额外的[包装脚本](https://github.com/CoderLine/alphaTab/blob/develop/packages/playground/alphatexLanguageServerWrap.ts)，然后导入[worker](https://github.com/CoderLine/alphaTab/blob/develop/packages/playground/alphatexLanguageServer.ts)。
